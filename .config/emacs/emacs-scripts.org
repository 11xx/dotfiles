Service template.

The ~Environment=COLORTERM=truecolor~ line is what gives ~emacsclient -t~
frames 24-bit color. Emacs decides terminal truecolor at C level (~init_tty~)
by reading ~COLORTERM~ from the daemon's *own* launch environment, not from the
per-frame environment the client forwards. Since systemd starts the daemon with
no terminal (~TERM=dumb~, no ~COLORTERM~), every ~-t~ frame would otherwise cap
at 256 colors and any ~:background~-driven face (region/rectangle, vertico,
etc.) degrades to a near-invisible approximation. Setting it here fixes it for
all named daemons. This assumes attachments come from truecolor terminals
(Alacritty), which holds for this setup.

#+begin_src systemd
[Unit]
Description=Emacs daemon (%i)
After=network.target

[Service]
Type=forking
Environment=COLORTERM=truecolor
ExecStart=emacs --daemon=%i
Restart=on-failure
RestartSec=5s
StartLimitIntervalSec=10min
StartLimitBurst=5

[Install]
WantedBy=default.target
#+end_src

The service starts the daemon directly, so there is no separate starter
script — the old =emacs-daemon-starter= wrapper only added an =sh -c= hop and a
=${1:-def}= default that a systemd template instance can never trigger.

** Client wrapper

Every entry point funnels through one wrapper, =emacsclient-named-daemon=, which
takes a daemon socket name as its first argument and infers the correct
frame/blocking mode from the invocation context — without overriding any frame
flag the caller passed explicitly. Keeping the inference here means it lives in
exactly one place; the per-daemon scripts below are thin shims that just select
a socket (and, for =code=, a fixed "fresh GUI frame" policy).

The frame-mode decision splits on three signals gathered from the argument
list: whether a frame flag was given, whether =-n/--no-wait= was given, and
whether any file targets are present (so a launcher/keybind call with no files
is told apart from a =$EDITOR= call with files). Options that consume a
following argument are skipped so their value isn't mistaken for a file.

#+begin_src zsh :tangle (expand-file-name "emacs/emacsclient-named-daemon" (xdg-bin-home))
local server=$1; shift
typeset -i nowait=0 has_frame_flag=0 has_files=0 skip_next=0 after_ddash=0

for arg in "$@"; do
    (( after_ddash )) && { has_files=1; continue }
    (( skip_next ))      && { skip_next=0; continue }

    case $arg in
        --)
            after_ddash=1 ;;
        -n|--no-wait)
            nowait=1 ;;
        -c|--create-frame|-t|--tty|-r|--reuse-frame)
            has_frame_flag=1 ;;
        # Options that consume the next argument (not a file)
        -e|--eval|-s|--socket-name|-f|--server-file|-d|--display|-F|--frame-parameters)
            skip_next=1 ;;
        -*)  ;;  # unknown flags — irrelevant to detection
        ,*)
            has_files=1 ;;
    esac
done

# Caller explicitly chose a frame mode — trust them, just wire the socket.
(( has_frame_flag )) && exec emacsclient -s $server "$@"

if (( nowait )); then
    # -n without a frame flag: fire-and-forget, default to GUI frame.
    exec emacsclient -s $server -c "$@"

elif (( !has_files )); then
    # No file targets: launcher/keybind call (Hyprland, dmenu, etc.)
    # Open a new GUI frame and return immediately to the caller.
    exec emacsclient -s $server -c -n "$@"

elif [[ -t 0 ]]; then
    # Files + controlling TTY: $EDITOR-style blocking call.
    # Take over the terminal; block until server-edit (C-x #).
    exec emacsclient -s $server -t "$@"

elif [[ -n $DISPLAY || -n $WAYLAND_DISPLAY ]]; then
    # Files + no TTY + display available: GUI app invoked $EDITOR.
    # New GUI frame, block until server-edit.
    exec emacsclient -s $server -c "$@"

else
    # Files + no TTY + no display: headless/SSH fallback.
    exec emacsclient -s $server -t "$@"
fi
#+end_src

** Named daemons

=def= is the general-purpose editor daemon wired to =$EDITOR=/=$VISUAL= and the
=s-x e e= keybind, so it wants the full context inference.

#+begin_src shell :tangle (expand-file-name "emacs/emacsclient-def" (xdg-bin-home))
exec emacsclient-named-daemon def "$@"
#+end_src

=code= is the dedicated code-session daemon, only reached from the =s-x e c=
keybind. Its policy is fixed: always pop a fresh GUI frame and return
immediately (=-c -n=), which the wrapper honours as an explicit frame choice.

#+begin_src shell :tangle (expand-file-name "emacs/emacsclient-code" (xdg-bin-home))
exec emacsclient-named-daemon code -c -n "$@"
#+end_src
