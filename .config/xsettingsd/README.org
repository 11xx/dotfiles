* Font config
#+begin_src conf
Xft/Antialias 1
Xft/HintStyle "hintfull"
Xft/Hinting 1
Xft/RGBA "rgb"

# Values other than "none" makes GDK fonts look horrible, at least for me.
# Set lcddefault on 'Xresources' and/or 'fontconfig/fonts.conf' instead.
Xft/lcdfilter "none"
#+end_src

* Customizing other GTK-specific settings
Prefer customizing =dconf= using =gsettings= for live changes. But if the
objective is to use a "set it and forget it" setup with config files
install =nwg-look=, specially for Wayland, and customize GTK config
files.
