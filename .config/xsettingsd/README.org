#+title: xsettingsd GTK configuration Daemon
#+description: This daemon tells running GTK applications how to render the new settings

- Dependencies
  + =xsettingsd=
  + =gnome-themes-extra=: for getting the default Adwaita themes.

* Theme & Icon theme

Separate theme files so one of them can be symlinked by darkman like
: ln -sf xsettingsd.conf.light xsettingsd.conf

#+begin_src conf :tangle xsettingsd.conf.dark :noweb tangle
Net/ThemeName "Adwaita-dark"

<<icons-theme>>

<<font-settings>>
#+end_src

#+begin_src conf :tangle xsettingsd.conf.light :noweb tangle
Net/ThemeName "Adwaita"

<<icons-theme>>

<<font-settings>>
#+end_src

#+NAME: icons-theme
#+begin_src conf :tangle no
Net/IconThemeName "Papirus"
Gtk/CursorThemeName "simp1e-amber-neron"
#+end_src

#+NAME: font-settings
#+begin_src conf
Xft/Antialias 1
Xft/Hinting 1
Xft/HintStyle "hintslight"
Xft/RGBA "rgb"
Xft/lcdfilter "lcddefault"
# Xft/DPI 112640
Xft/DPI 117760 # 115 DPI × 1024.
#+end_src

- =Xft/Hinting 1= = enable hinting at all
- =Xft/HintStyle= = choose strength/style
  + =hintnone=: no hinting; most faithful outlines, blurrier at small sizes
  + =hintslight=: light alignment mainly vertically; usually best-looking default
  + =hintmedium=: stronger alignment; sharper, a bit more shape distortion
  + =hintfull=: strongest alignment to pixel grid; crispest/smallest text, most distortion


* More settings
See https://codeberg.org/derat/xsettingsd#settings
DPI = (Width*Height) / (Screen Inch Size, e.g. 24)

* Customizing other GTK-specific settings
Prefer customizing =dconf= using =gsettings= for live changes. But if the
objective is to use a "set it and forget it" setup with config files
install =nwg-look=, specially for Wayland, and customize GTK config
files.
