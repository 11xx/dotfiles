* Notes
** Import Zsh history from custom file
: HISTFILE=$(readlink -f ./history) atuin import zsh
- where
  + =HISTFILE= is =zsh='s variable for setting the history file path.
  + =./history= is the path of the file. Using =readlink -f= expands the
    input relative path to a full path, for redundancy.
