Edit the lines from =pipewire.conf= to the desired values e.g.
#+begin_example
default.clock.rate          = 192000
default.clock.allowed-rates = [ 44100 48000 88200 96000 176400 192000 352800 384000 705600 768000 ]
#+end_example
# [2023-03-13 Mon 03:45:52 -03]
# #default.clock.rate          = 48000

To check which sampling rates are supported natively, run:
: grep 'Rates:' /proc/asound/card0/stream0 | uniq
To get a list accepted by =default.clock.allowed-rates=:
: grep 'Rates:' /proc/asound/card0/stream0 | uniq | sed -E 's/(^\s*Rates:\s|,)//g'
- See
  + [[https://unix.stackexchange.com/questions/493929/pulseaudio-how-to-determine-native-sample-rates-and-bit-depths-supported-by-ha][PulseAudio: How to determine native sample rates and bit depths, supported by hardware? - Unix & Linux Stack Exchange]] \\
    # [2023-03-28 Tue 13:47:36 -03]
  + [[#orgid-hrtmur][pipewire.conf]]

Then set =resample.quality = 15= on both [[#orgid-nnjzys][pipewire-pulse.conf]] and
[[#orgid-xozths][client.conf]].

Sample rates can be changed manually with:
: pw-metadata -n settings 0 clock.force-rate 48000
- See
  [[https://www.reddit.com/r/linuxaudio/comments/unutlu/how_to_change_sample_rate_in_pipewire/][how to change sample rate in pipewire : linuxaudio]]

- After changes, restart =pipewire= and =pipewire-pulse=:
  : systemctl --user restart pipewire pipewire-pulse

* =pipewire.conf=
:PROPERTIES:
:header-args:conf: :tangle "pipewire.conf.d/20-quality.conf" :mkdirp yes

The default example file can be found in:
: /usr/share/pipewire/pipewire.conf

As stated in the header comments of the =pipewire.conf= file:
#+begin_quote
It is also possible to place a file with an updated section in
=/etc/pipewire/pipewire.conf.d/= for system-wide changes or in
=~/.config/pipewire/pipewire.conf.d/= for local changes.
#+end_quote

#+begin_src conf :noweb yes
context.properties = {
    ## Configure properties in the system.
    link.max-buffers                      = 64

    ## Properties for the DSP configuration.
    default.clock.rate          = 48000
    default.clock.allowed-rates = [ <<card0-supported-sampling-rates-pipewire-list()>> ]
}
#+end_src

#+NAME: card0-supported-sampling-rates-pipewire-list
#+begin_src shell :tangle no
grep 'Rates:' /proc/asound/card0/stream0 | uniq | sed -E 's/(^\s*Rates:\s|,)//; s/,//g'
#+end_src

Copy and edit this file in =/etc/pipewire= for system-wide changes
or in =~/.config/pipewire= for user-local changes.

As stated in the header comment of the =client.conf= file:
#+begin_quote
It is also possible to place a file with an updated section in

#+end_quote

- [[https://wiki.archlinux.org/title/PipeWire#Sound_quality_(resampling_quality)][According the the Arch Wiki]] the maximum =resample.quality= value
  is =14=.
#+begin_src conf
stream.properties = {
    resample.quality      = 14
}
#+end_src
