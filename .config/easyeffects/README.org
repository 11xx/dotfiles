* Web Audio High compressor

The browser extension's High preset displays a -50 dB threshold, a 30 dB
soft-knee width, a 20:1 ratio, a 3 ms attack, and a 250 ms release.  A direct
numeric copy does not preserve its response: LSP applies substantially more
gain reduction at the same nominal threshold.

Firefox's Web Audio implementation also applies 18.63 dB of implicit makeup
gain for this curve.  The system-wide default deliberately uses half that
linear gain, 12.61 dB, which lowers the complete response and its loud-end
target by 6.02 dB.  The peak detector follows the browser behavior, and the
maximum of both channels keeps stereo linking independent of channel
correlation.

An offline steady-signal sweep from -80 through 0 dBFS maps the audible Web
Audio curve to an LSP threshold of -34 dB and a -16 dB knee.  This calibrated
curve stays within roughly 0.75 dB of Firefox across the sweep, including the
-13.3 dBFS loud-end ceiling, instead of the roughly 15 dB loud-end mismatch
produced by copying the displayed threshold directly.

* XHigh compressor

The secondary profile starts reducing gain earlier and approaches the same
-19.35 dBFS loud-end target more tightly.  A 40:1 ratio, faster attack, longer
release, and a small lookahead suppress sudden peaks while avoiding rapid
level recovery between words.  Its larger makeup value compensates for the
additional reduction: it raises quiet material more strongly without raising
the measured maximum above the default profile.

* Toggle command

=audio-compressor= treats the Web Audio preset as one feature rather than
blindly toggling whatever Easy Effects happens to be doing.  Calling it with
no argument turns either compressor off when active and otherwise restores the
last selected profile.  The =high=, =xhigh=, and =default= commands select and
remember a profile; =default= selects =high=.  =on= restores the remembered
profile, falling back to =high= before the first selection.  The one-line state
file lives directly in =$XDG_DATA_HOME=.

#+begin_src shell :tangle (expand-file-name "audio-compressor" (xdg-bin-home)) :shebang #!/usr/bin/env sh :tangle-mode o755
set -eu

high_preset='Web Audio High'
xhigh_preset='Web Audio XHigh'
state_file="${XDG_DATA_HOME:-$HOME/.local/share}/audio-compressor-profile"
service='easyeffects.service'
runtime_dir="${XDG_RUNTIME_DIR:-/run/user/$(id -u)}"
socket="${runtime_dir}/EasyEffectsServer"

notify() {
    command -v notify-send >/dev/null 2>&1 || return 0
    notify-send \
        -a 'Audio Compressor' \
        -h string:x-canonical-private-synchronous:audio-compressor \
        "Audio compression $1"
}

wait_for_server() {
    attempts=0
    while [ ! -S "$socket" ]; do
        attempts=$((attempts + 1))
        if [ "$attempts" -ge 50 ]; then
            printf 'audio-compressor: Easy Effects did not become ready\n' >&2
            return 1
        fi
        sleep 0.1
    done
}

start_server() {
    if ! systemctl --user is-active --quiet "$service"; then
        systemctl --user start "$service"
    fi
    wait_for_server
}

remembered_profile() {
    profile=$(cat "$state_file" 2>/dev/null || :)
    case "$profile" in
        high|xhigh) printf '%s\n' "$profile" ;;
        *) printf 'high\n' ;;
    esac
}

enable_profile() {
    start_server
    profile=$1
    case "$profile" in
        high) preset=$high_preset ;;
        xhigh) preset=$xhigh_preset ;;
        *) return 64 ;;
    esac
    easyeffects --load-preset "$preset"
    easyeffects --bypass 2
    mkdir -p "${state_file%/*}"
    printf '%s\n' "$profile" > "$state_file"
    notify "enabled (${profile})"
}

disable_compressor() {
    if systemctl --user is-active --quiet "$service"; then
        wait_for_server
        easyeffects --bypass 1
    fi
    notify disabled
}

active_profile() {
    systemctl --user is-active --quiet "$service" || return 1
    wait_for_server
    [ "$(easyeffects --bypass 3)" = 2 ] || return 1
    case "$(easyeffects --last-loaded-preset output)" in
        "$high_preset") printf 'high\n' ;;
        "$xhigh_preset") printf 'xhigh\n' ;;
        *) return 1 ;;
    esac
}

case "${1:-toggle}" in
    toggle)
        if active_profile >/dev/null; then
            disable_compressor
        else
            enable_profile "$(remembered_profile)"
        fi
        ;;
    on)
        enable_profile "$(remembered_profile)"
        ;;
    default|high)
        enable_profile high
        ;;
    xhigh)
        enable_profile xhigh
        ;;
    off)
        disable_compressor
        ;;
    status)
        if profile=$(active_profile); then
            printf '%s\n' "$profile"
        else
            printf 'off\n'
        fi
        ;;
    *)
        printf 'usage: audio-compressor [toggle|on|default|high|xhigh|off|status]\n' >&2
        exit 64
        ;;
esac
#+end_src

* Systemd user service
:PROPERTIES:
:CUSTOM_ID: systemd-user-service
:tangle-dir: (expand-file-name "systemd/user" (xdg-config-home))
:END:

Easy Effects stays available as a hidden graphical-session service, so the
toggle command never opens its window.  Automatic processing of every output
and input stream is disabled before startup.  Only explicitly routed streams
target the processing sink or source, while ordinary playback and capture stay
on their hardware paths.

#+begin_src systemd :tangle (tdir "easyeffects.service")
[Unit]
Description=Easy Effects audio processing
After=pipewire.service wireplumber.service
PartOf=graphical-session.target

[Service]
Type=exec
ExecStartPre=/usr/bin/kwriteconfig6 --file %h/.config/easyeffects/db/easyeffectsrc --group EffectsPipelines --key processAllOutputs false
ExecStartPre=/usr/bin/kwriteconfig6 --file %h/.config/easyeffects/db/easyeffectsrc --group EffectsPipelines --key processAllInputs false
ExecStart=/usr/bin/easyeffects --service-mode
Restart=on-failure
RestartSec=2

[Install]
WantedBy=graphical-session.target
#+end_src
