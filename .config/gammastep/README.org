#+TITLE: gammastep: Wayland support for 'blue-light filter' & gamma correction
As of Nvidia driver 545.29.02 GAMMA LUT is officially supported so
night light can now be used.

Example command line
: gammastep -P -t 6500:2400 -g 1.3 -l -23.5:-46.6
=6500= seems to be the default so use it during the day.

* config file
:PROPERTIES:
:header-args:conf: :tangle config.ini
:END:
#+begin_src conf
[general]
temp-night=2400
# fade=0
gamma=1.3
location-provider=manual

[manual]
lat=-23.5
lon=-46.6
#+end_src

* =gammastep-toggle=: Temporarity disable gammastep
:PROPERTIES:
:header-args:shell: :tangle (concat (xdg-bin-home) "/gammastep-toggle") :shebang #!/usr/bin/env sh
:END:

Untill toggled again, same as [[redshift-toggle]].
#+begin_src shell
pkill -USR1 gammastep
#+end_src
