- [[https://wiki.archlinux.org/title/XDG_Desktop_Portal#Configuration][ArchWiki/XDG Desktop Portal#Configuration]]

In the =portals.conf= file set ~org.freedesktop.impl.portal.*=PORTAL~ where PORTAL is a desktop
portal implementation.

* Hyprland-specific overrides
:PROPERTIES:
:CUSTOM_ID: orgid-rhgutk
:END:
- [[https://wiki.hyprland.org/Useful-Utilities/xdg-desktop-portal-hyprland/#using-the-kde-file-picker-with-xdph][Hyprland Wiki/Hyprland Desktop Portal#Using the KDE file picker with XDPH]]

#+begin_src conf :tangle hyprland-portals.conf
[preferred]
default=hyprland;kde
org.freedesktop.impl.portal.Settings=darkman
org.freedesktop.impl.portal.FileChooser=kde
#+end_src
- where
  + =;= semicolons allow specifying order of fallback
  + =;*= is a fallback for activating any other portal found. In special
    for =Settings= this makes GTK apps using =GTK_USE_PORTAL=1= that
    didn't pick up settings from the portal activate
    =xdg-desktop-portal-gtk= for example (Note that using
    ~GTK_USE_PORTAL=1~ may cause more issues. See
    [[xdg-desktop-portal-gtk-use-portal-problem-note]]
  + I don't know the difference between "=;*=" vs "=;*;=" at the end of
    fallbacks
  + ~FileChooser=kde~ is probably reduntant with ~default=kde~ but keeping
    in case =default= is changed in the future or vice-versa.
  # keeping it just bc
