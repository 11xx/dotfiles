** =wob-volume=: Script to setup wob for volume
:PROPERTIES:
:header-args:shell: :tangle (tdir "wob-volume") :shebang #!/usr/bin/env sh
:CUSTOM_ID: orgid-snwuth
:END:

Foreground variant of the default bar that live-reloads while you edit
=wob.ini=: =entr= watches the config and restarts the reader on every save.
Prefer [[#orgid-wobvolumepw][=wob-volume-pw=]] for normal use (background,
self-healing); reach for this one only while tweaking the config. Run one or
the other, not both — they read the same pipe.

Dependencies: =wob=, =entr=.

The pipe and config resolve through XDG with =/tmp= / =~/.config= fallbacks,
and it shares the default bar's pipe so =pw-volume='s output shows up here too.
A leading =-v= turns on shell tracing. The pre-launch =pkill= is scoped to this
bar's own reader by its config path, so the per-sink bars are left alone (the
old =killall wob= used to take them all down).

#+begin_src shell
[ "$1" = -v ] && { set -x; shift; }

wobPipe="${XDG_RUNTIME_DIR:-/tmp}/pw-volume.wob"
wobConfig="${XDG_CONFIG_HOME:-$HOME/.config}/wob/wob.ini"

[ -p "$wobPipe" ] || { rm -f "$wobPipe"; mkfifo "$wobPipe"; }
pkill -f "wob -c $wobConfig" 2>/dev/null

printf '%s\n' "$wobConfig" |
    entr -r -- sh -c "tail -f \"$wobPipe\" | wob -c \"$wobConfig\""
#+end_src

** =wob-instance=: Instance monitor starter for custom pipes and config
:PROPERTIES:
:header-args:shell: :tangle (tdir "wob-instance") :shebang #!/usr/bin/env sh
:CUSTOM_ID: orgid-wobinstance
:END:

Starts one =wob= reader for a given =(pipe, config)= pair. Takes the pipe and
config as arguments so the same script drives the default bar and every
per-sink bar.

The instance is intentionally replace-on-start. Hyprland crashes can leave the
old shell holding the lock after the visible =wob= process lost its Wayland
connection, so a fresh login/startup should take the pipe back instead of
silently exiting behind a stale lock. The FIFO is recreated under the lock on
each start, which keeps the path and the live reader in sync. During normal
operation the shell opens the FIFO read-write and hands that fd directly to
=wob=, so there is no =tail=, =cat=, or =timeout= process in the hot path.

#+begin_src shell
# Usage: wob-instance <PIPE_PATH> <CONFIG_FILE>

PIPE="$1"
CONFIG="$2"

if [ -z "$PIPE" ] || [ -z "$CONFIG" ]; then
    echo "Usage: $0 PIPE_PATH CONFIG_FILE" >&2
    exit 1
fi

LOCK="${PIPE}.lock"
PIDFILE="${PIPE}.pid"

stop_owner() {
    pids=""

    [ -r "$PIDFILE" ] && pids="$(cat "$PIDFILE" 2>/dev/null || :)"
    if command -v fuser >/dev/null 2>&1; then
        pids="$pids $(fuser "$LOCK" 2>/dev/null || :)"
    fi

    pids="$(printf '%s\n' $pids | awk -v self="$$" '$1 ~ /^[0-9]+$/ && $1 != self { print }' | sort -u)"
    [ -n "$pids" ] || return 0

    kill $pids 2>/dev/null || :
    i=0
    while [ "$i" -lt 20 ]; do
        live=""
        for pid in $pids; do
            kill -0 "$pid" 2>/dev/null && live="$live $pid"
        done
        [ -z "$live" ] && return 0
        i=$((i + 1))
        sleep 0.05
    done

    kill -KILL $pids 2>/dev/null || :
}

cleanup() {
    [ "$(cat "$PIDFILE" 2>/dev/null || :)" = "$$" ] && rm -f "$PIDFILE" "$PIPE"
}

trap cleanup EXIT
trap 'cleanup; exit 0' INT TERM HUP

exec 9>"$LOCK"
if ! flock -n 9; then
    stop_owner
    flock -w 2 9 || exit 1
fi

printf '%s\n' "$$" > "$PIDFILE"
rm -f "$PIPE"
mkfifo -m 600 "$PIPE"

exec 3<>"$PIPE"
wob -c "$CONFIG" <&3 &
wait "$!"
#+end_src

** =wob-volume-pw=
:PROPERTIES:
:header-args:shell: :tangle (tdir "wob-volume-pw") :shebang #!/usr/bin/env zsh
:CUSTOM_ID: orgid-wobvolumepw
:END:

The default bar, started once at login (=exec_once= in the Hyprland config).
Hands the default pipe and config to [[#orgid-wobinstance][=wob-instance=]] and
detaches it into its own session. The pipe path matches =pw-volume='s built-in
default, so a bare =pw-volume @DEFAULT_AUDIO_SINK@ …= (no =WOB_PIPE=) lands
here.

#+begin_src shell
wobPipe="${XDG_RUNTIME_DIR:-/tmp}/pw-volume.wob"
wobConfig="${XDG_CONFIG_HOME:-$HOME/.config}/wob/wob.ini"
setsid -f wob-instance "$wobPipe" "$wobConfig"
#+end_src

** =wob-volume-pw-extras=
:PROPERTIES:
:header-args:shell: :tangle (tdir "wob-volume-pw-extras") :shebang #!/usr/bin/env zsh
:END:

The per-sink bars (browser-sink, game-sink), also started once at login. Each
gets its own pipe under =$XDG_RUNTIME_DIR= and its own config, matching the
=WOB_PIPE== paths the volume keybinds export. Add a sink by dropping in a
=wob-<name>-sink.ini= and one more line here.

#+begin_src shell
wobRuntime="${XDG_RUNTIME_DIR:-/tmp}"
wobConfigDir="${XDG_CONFIG_HOME:-$HOME/.config}/wob"
setsid -f wob-instance "$wobRuntime/wob-browser-sink.pipe" "$wobConfigDir/wob-browser-sink.ini"
setsid -f wob-instance "$wobRuntime/wob-game-sink.pipe"    "$wobConfigDir/wob-game-sink.ini"
#+end_src
