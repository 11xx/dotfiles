#+TITLE: rmpc: Rusty Music Player Client, TUI, supports album art

* =rmpc.ron=: config file
:PROPERTIES:
:header-args:ron: :tangle (expand-file-name "rmpc/config.ron" (xdg-config-home)) :mkdirp yes
:END:

- The default config can be generated with:
  : rmpc config
  see [[https://mierak.github.io/rmpc/reference/config/][Default config | rmpc]]

- [[https://mierak.github.io/rmpc/configuration/][General configuration | rmpc]]

- Note: For creating key combinations with Alt (aka Meta), the syntax
  does not use =M= as in the Emacs format, it uses =A= for =Alt=, e.g. =<A-v>=
  for =Alt + v=.
