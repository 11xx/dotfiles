#+TITLE: btop notes

The config file is managed by the TUI itself so make manual changes to
the file as necessary. It's not really worth it to have it "frozen".

- [[https://github.com/aristocratos/btop#configurability][aristocratos/btop: A monitor of resources#Configurability]]

Example exclude list setting for BTRFS subvolumes present in =fstab=:
#+begin_src conf
#* Optional filter for shown disks, should be full path of a mountpoint, separate multiple values with whitespace " ".
#* Begin line with "exclude=" to change to exclude filter, otherwise defaults to "most include" filter. Example: disks_filter="exclude=/boot /home/user".
disks_filter = "exclude=/.snapshots /btrfs /home /tmp /var /var/log /var/cache/pacman/pkg /var/tmp /var/lib/flatpak /var/cache /home/games /nix/store /guix/store"
#+end_src
- Note: apparently mountpoints must /not/ have a trailing =/=.
