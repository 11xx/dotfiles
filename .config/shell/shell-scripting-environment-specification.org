The idea here is how shell scripting can have supporting libraries for
it's scripts. Similarly to ~#include~ in C or ~import~ +in every other
language+.

* PATH libraries
- The objective is to add the functionality of a "load path" to
  scripts with minimal setup, e.g.:
  : mkdir $HOME/.shlib
- Add it to path
  : PATH=$PATH:$HOME/.shlib
- Create a "shell library" file and place it in =$HOME/.shlib=. The name
  of that shell library file have to be unique, standarized and
  different than any other script in PATH. The convention is up to the
  user, so here's some suggestions:
  + =@name= or =@@name=, because almost no script begins with =@=, or double
    the =@@= for double the disambiguation.
  + =#name= or =##name=, (same as before).
  # + =.@name= or =@.name=, because a name like a dotfile "=.name="
  # would be similar to directories that are also executable. The dot
  # (=.=) refers to a sourceable file.
  + =#include_= or =#include-=, to be similar to C. This also clarifies
    that the file is meant to be sourced.
