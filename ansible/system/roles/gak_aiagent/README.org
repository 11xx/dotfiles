#+TITLE: Gak agent workload bootstrap

The =gak-aiagent= inventory host connects as =aiagent= with its own operator-held
SSH key. The Guix system service supplies a mounted home, a private runtime
directory, SSH cgroup placement and a capped parent before this role runs.
The play installs Python and =podman-compose= in the account's Guix profile.

This role keeps Podman storage, its runroot and both temporary directories in
the ext4 home image. Its storage configuration declares one graphroot and a
separate runroot. The account's shell and Shepherd service set =TMPDIR=,
=CONTAINERS_IMAGE_COPY_TMPDIR= and =XDG_RUNTIME_DIR=. Podman's cgroupfs manager
uses =cgroups = "split"=, placing conmon and the payload beneath the cgroup
of the service or SSH session that starts them.
The image initializer reserves 256 GiB only when another 128 GiB remains free
for the operator's services. It removes a partial candidate on failure and
cleans up a candidate left by an interruption before retrying. Formatting
eagerly initializes ext4 inode tables and the journal. An existing image with
holes is re-reserved without changing data when free space covers its missing
allocation plus the 128 GiB host reserve.
The home service stays running while the image is mounted; runtime and cgroup
setup are repeatable one-shots. Each prerequisite finishes before the
lifecycle helper starts. Home creation and unmount hold the same root-only
lock. Lock acquisition and disk operations have finite deadlines, with timed
process groups terminated on expiry. A failed unmount can leave the image
mounted even when Shepherd reports the service stopped, so =findmnt= determines
the actual mount state.
Stopping Compose kills residual processes in its service cgroup after the
helper exits. Stopping the home asks Podman as aiagent to stop all containers
before it kills the full delegated cgroup, including SSH
sessions, waits up to one minute for it to empty, removes empty descendant
cgroups and then unmounts. Podman's runtime cgroup and stale SSH leaves are
cleared; the service and delegated roots remain.
Before Compose starts, this instance reconciles records that still say running
although the payload or conmon PID has died. It uses Podman's stop transition
on those records and leaves healthy containers and their writable layers in
place. The check is bounded to one minute.
Both launch paths put =/run/privileged/bin= first so Podman resolves Guix's
setuid =newuidmap= and =newgidmap= wrappers.
The host account has tailscaled's non-operator read-only local API access;
the Guix module leaves the socket unchanged. The agent container must omit
host runtime paths, including that socket.

The =agent= Compose project names =localhost/aiagent-fedora:44-v1= and has no
=build:= key. Its build context lives under =/home/aiagent/image=. The
account-local =aiagent build= command builds that tag, with Podman's storage and
temporary paths inside the home image. It refuses to overwrite an existing
initial tag. The project mounts only
=container-home= at =/home/node=, =workspaces= at =/work= and =cache= at
=/cache=. The container uses =keep-id= for the agent's host UID. No host
runtime, socket, media path or operator home is mounted. The image installs
harness binaries and wrappers under =/usr/local=, outside the persistent home.
The Fedora 44 base and harness package versions are pinned in
[[file:../../aiagent.org][aiagent.org]]. Pi's interactive TUI segfaults in this
environment, so container Pi is for print mode.

=aiagent status=, =logs=, =shell= and =exec= inspect or enter the container.
=build=, =start=, =stop=, =restart=, =recreate= and =cache-clean= hold one
account-local lock. =cache-size= reports the disposable cache subtree;
=cache-clean= removes only that subtree's contents. Harness logins and project
work remain in the separate persistent mounts. The 32 GiB cache target is
operator-maintained through =cache-size= and explicit =cache-clean=; the home
image's 256 GiB size is the hard account budget.

The helper reads its five instance lists from =/home/aiagent/services= and
starts the project with =--pull never=. The =gak-aiagent-image= Ansible tag
deploys the context, command, private directories and Compose file without
changing the running instance lists. Build the image through an aiagent SSH
session. Stop =aiagent-compose= before deploying the full role, then start the
service under operator control. The
service's lifecycle lock is held while it runs, and its recorded project list
must match the deployed declarations before it stops. A second play run is
idempotent.
