#+TITLE: prowlarr

This role owns the Compose project in =templates/compose.yaml.j2=.
Its persistent state is under =~/services/prowlarr= on the NVMe.
The web backend uses host port 8888. Verify indexer tests and synchronization with its applications.

Use =podman compose -f ~/services/prowlarr/compose.yaml ps= and =podman logs
prowlarr= for diagnostics. Update explicitly with =podman compose -f
~/services/prowlarr/compose.yaml pull= followed by =up -d --force-recreate
--pull never=. Copy complete state with ownership preserved before an image
change, and retain the previous image until indexer checks pass.

See [[file:../../GAK-SERVICES.org][service maintenance]] for deployment and image updates.
