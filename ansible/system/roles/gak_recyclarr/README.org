#+TITLE: recyclarr

This role owns the container declaration in =templates/containers.scm.j2=.
Its persistent state is under =~/services/recyclarr= on the NVMe.
This is a batch service with automatic startup disabled. Run sudo herd start
recyclarr explicitly. Ansible owns its YAML configuration and deploys the
Sonarr API key with =no_log= and mode 0640. The file remains owned by the
runtime user, with its group mapped to the application's container GID so the
non-root process can read it. Verify Sonarr configuration after synchronization.

Use =sudo herd status recyclarr= to inspect Shepherd and =podman logs recyclarr=
for application diagnostics. Before an image upgrade, stop the application,
copy its complete state with ownership preserved to a separate backup disk,
and restart it. Protect copies containing credentials. Restore into an isolated
state directory and verify the application before replacing production state.

See [[file:../../GAK-SERVICES.org][service maintenance]] for deployment and image updates.
