#+TITLE: sonarr

This role owns the container declaration in =templates/containers.scm.j2=.
Its persistent state is under =/media/.config/sonarr= on the HDD.
The web backend uses gak_sonarr_port. Recyclarr consumes the same port. Verify database access, download-client connectivity and library paths.

Use =sudo herd status sonarr= to inspect Shepherd and =podman logs sonarr=
for application diagnostics. Before an image upgrade, stop the application,
copy its complete state with ownership preserved to a separate backup disk,
and restart it. Protect copies containing credentials. Restore into an isolated
state directory and verify the application before replacing production state.

See [[file:../../GAK-SERVICES.org][service maintenance]] for deployment and image updates.
