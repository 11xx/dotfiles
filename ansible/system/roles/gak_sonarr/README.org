#+TITLE: sonarr

This role owns the Compose project in =templates/compose.yaml.j2=.
Its persistent state is under =~/services/sonarr= on the NVMe.
The web backend uses gak_sonarr_port. Recyclarr consumes the same port. Verify database access, download-client connectivity and library paths.

Use =podman compose -f ~/services/sonarr/compose.yaml ps= and =podman logs
sonarr= for diagnostics. Update explicitly with =podman compose -f
~/services/sonarr/compose.yaml pull= followed by =up -d --force-recreate
--pull never=. Copy complete state with ownership preserved before an image
change, and retain the previous image until database, download-client and
library checks pass.

See [[file:../../GAK-SERVICES.org][service maintenance]] for deployment and image updates.
