#+TITLE: qbittorrent

This role owns the Compose project in =templates/compose.yaml.j2=.
Its persistent state is under =~/services/qbittorrent= on the NVMe.
The web backend uses host port 9191; peer traffic uses host TCP/UDP port 12671. Preserve the complete config directory, including torrent resume metadata. Verify existing torrents and download paths.

Use =podman compose -f ~/services/qbittorrent/compose.yaml ps= and =podman logs
qbittorrent= for diagnostics. Update explicitly with =podman compose -f
~/services/qbittorrent/compose.yaml pull= followed by =up -d --force-recreate
--pull never=. Copy complete state with ownership preserved before an image
change, and retain the previous image until torrent resume, peer-port and
download checks pass.

See [[file:../../GAK-SERVICES.org][service maintenance]] for deployment and image updates.
