#+TITLE: jellyfin

This role owns the Compose project in =templates/compose.yaml.j2=.
Its persistent state is under =~/services/jellyfin= on the NVMe.
The web backend uses host port 9292. State includes config and cache directories. Verify real playback and any configured transcoding.

Use =podman compose -f ~/services/jellyfin/compose.yaml ps= and =podman logs
jellyfin= for diagnostics. Update explicitly with =podman compose -f
~/services/jellyfin/compose.yaml pull= followed by =up -d --force-recreate
--pull never=. Copy complete state with ownership preserved before an image
change, and retain the previous image until playback and transcoding checks
pass.

See [[file:../../GAK-SERVICES.org][service maintenance]] for deployment and image updates.
