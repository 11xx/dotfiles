#+TITLE: Shared media storage

This role owns the shared /media and /media/.config directories on the HDD.
Application roles own container declarations and supporting configuration.
The media tree remains at /media/Media. Runtime state stays under
/media/.config/APPLICATION; applications own their mutable configuration.

Selected configuration snapshots in the private vault are not complete
database or download-state backups. See [[file:../../GAK-SERVICES.org][service maintenance]].

* Users and groups

Application UID/GID values are container identities. Host file ownership
depends on the complete rootless UID/GID maps; matching numbers do not imply
matching identities. Inspect the maps and existing directory owners before
changing them. Shared media permissions must also work for NFS clients.

An =s6-applyuidgid= failure with =Invalid argument= can mean the requested
UID or supplementary group is absent from the container map. A container may
remain running while its application never starts. Check the HTTP endpoint,
not only =podman ps=. Test candidate maps with disposable containers and a
scratch bind mount before changing production ownership or mappings.

* Starting it

The containers are system Shepherd services and start at boot:

#+begin_src sh
sudo herd status sonarr
sudo herd restart jellyfin
#+end_src

recyclarr is a batch job, not a server: it syncs custom formats into Sonarr and
exits. It is declared =auto-start? #f=, because a container that exits on
purpose would otherwise read as a service that failed at every boot. Run it when
wanted:

#+begin_src sh
sudo herd start recyclarr
#+end_src
