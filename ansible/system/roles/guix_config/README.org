#+TITLE: Gak Guix declarations

This role deploys the rendered system and Home expressions, channels and
load-path modules to the operator's configuration directory. System activation
is an explicit operator step. Build and reconfigure with the module directory
on the Guix load path:

#+begin_src sh
guix system build -L ~/.config/guix/modules ~/.config/guix/system.scm
sudo guix system reconfigure -L ~/.config/guix/modules ~/.config/guix/system.scm
#+end_src

A successful build does not execute generated Guile programs. On a host with
the =aiagent= account, stage and run the root-path probe before activating a
revised module. From =ansible/system=, with the module tree staged on gak:

#+begin_src sh
scp roles/guix_config/tests/aiagent-root-path.py \
  gak:.cache/gak-aiagent-host/slice2/aiagent-root-path.py
ssh gak 'python3 ~/.cache/gak-aiagent-host/slice2/aiagent-root-path.py ~/.cache/gak-aiagent-host/slice2/modules'
#+end_src

The probe builds each program and uses
=podman unshare= with scratch targets for root-only paths. It performs real
=setgroups=, =setgid=, =setuid=, cgroup writes and ownership changes without
touching the running agent services. A loop mount cannot be created by the
unprivileged namespace; the probe checks that invocation reaches loop setup
with correctly typed arguments, then checks the post-mount ownership path
with that operation mocked.

The =aiagent host= module is tangled from [[file:../../aiagent.org][aiagent.org]]. Its
selection is controlled by =gak_aiagent_host_enabled=. The operator's rootless
Podman declaration remains separate, including its subordinate IDs. A change
to a deployed module reports a pending system activation even when the main
expression is unchanged.
