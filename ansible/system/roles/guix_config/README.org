#+TITLE: Gak Guix declarations

This role deploys the rendered system and Home expressions, channels and
load-path modules to the operator's configuration directory. System activation
is an explicit operator step. Build and reconfigure with the module directory
on the Guix load path:

#+begin_src sh
guix system build -L ~/.config/guix/modules ~/.config/guix/system.scm
sudo guix system reconfigure -L ~/.config/guix/modules ~/.config/guix/system.scm
#+end_src

A successful build does not execute generated Guile programs. On a host with
the =aiagent= account, stage and run the root-path probe before activating a
revised module. From =ansible/system=, with the module tree staged on gak:

#+begin_src sh
scp roles/guix_config/tests/aiagent-root-path.py \
  gak:.cache/gak-aiagent-host/check/aiagent-root-path.py
ssh gak 'python3 ~/.cache/gak-aiagent-host/check/aiagent-root-path.py ~/.cache/gak-aiagent-host/check/modules'
#+end_src

The probe builds each program and uses =podman unshare= with scratch targets
for root-only paths. It exercises runtime lock creation and reuse, both cgroup
drain modes, and the home start and stop programs. Namespace root is not host
root. Guile performs real =setgroups=, =setgid=, =setuid=, =mkdir=, =chown=,
=chmod= and descriptor =stat= calls. Cgroup
targets are ordinary files: they test argument types and file operations, not
kernel placement or delegation. Preopened =/proc/self/fd= paths allow the
post-drop =chdir= and =execl= calls without testing ancestor-directory
traversal. The namespace denies loop-device setup; successful mount and
unmount results are mocked to exercise the following Guile ownership calls.

The =aiagent host= module is tangled from [[file:../../aiagent.org][aiagent.org]]. Its
selection is controlled by =gak_aiagent_host_enabled=. The operator's rootless
Podman declaration remains separate, including its subordinate IDs. A change
to a deployed module reports a pending system activation even when the main
expression is unchanged.

The =aiagent git-hub= module is tangled from the same Org source and selected
by =gak_git_hub_enabled=. It selects Guix's =gitolite-service-type= with the
private =agentgit= account. Its home is =/var/lib/agentgit=, outside the
agent's mounted home. =gak_git_hub_admin_public_key= names the operator's
public key; =gak_git_hub_max_push_bytes= bounds each incoming pack stream.
The two service selections can be removed independently. The reference
[[file:files/git-hub/gitolite.conf][Gitolite policy]] belongs in the
=gitolite-admin= repository with the agent's public key at
=keydir/aiagent.pub=. Only the operator pushes that administrative repository.
The private agent key stays in the container home on gak.

The module installs its Gitolite receive trigger from root-controlled
=/etc/git-hub= and creates =/var/lib/agentgit-lock/receive.lock= as a
root-owned file writable by the private hub group. The hub cannot replace its
root-owned parent directory. Receive commands hold this lock through Gitolite
administrative hooks; root backup checks the same inode before it captures
both repositories and completes the Restic snapshot.
