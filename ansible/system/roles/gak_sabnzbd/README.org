#+TITLE: sabnzbd

This role owns the Compose project in =templates/compose.yaml.j2=.
Its persistent state is under =~/services/sabnzbd= on the NVMe.
The web backend uses host port 9090. Verify queue state and a completed download after an update.

Use =podman compose -f ~/services/sabnzbd/compose.yaml ps= and =podman logs
sabnzbd= for diagnostics. Update explicitly with =podman compose -f
~/services/sabnzbd/compose.yaml pull= followed by =up -d --force-recreate
--pull never=. Copy complete state with ownership preserved before an image
change, and retain the previous image until queue and download checks pass.

See [[file:../../GAK-SERVICES.org][service maintenance]] for deployment and image updates.
