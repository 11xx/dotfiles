* Gak host foundation

The =aiagent= account has a private group and a mounted home backed by a
preallocated ext4 image. The backing image is root-owned. Shepherd establishes
the mount, runtime directory and capped cgroup before starting its Compose
helper. SSH sessions enter the delegated cgroup through PAM before launching
the user's command. The delegated directory belongs to aiagent; its parent,
the limit files and each =cgroup.kill= file belong to root. Gak uses Podman's
cgroupfs manager. Its per-user
=containers.conf= selects =cgroups = "split"=, so conmon and each container
payload become children of the service or SSH session cgroup that launched
Podman. Image builds inherit that placement. No container parent is specified
in Compose.
Shepherd waits for each host prerequisite program to exit successfully before
starting the helper. The mounted home remains a running service so stopping
it first stops the helper, asks Podman as aiagent to stop every container,
kills any remaining process in the delegated cgroup, and then unmounts the
image. The kill includes SSH sessions. Stopping
Compose alone lets its helper finish and then kills residual processes in the
service subtree, so a restart begins without a retained Podman pause process.
Before the helper starts, aiagent's instance checks running Podman records
against their payload and conmon PIDs. It asks Podman to stop only stale
records and verifies that each leaves the running state. Healthy containers
and their writable layers remain in place.
Runtime and cgroup setup remain one-shots: their directories and limit writes
are idempotent, and they have no mount to undo. Runtime setup creates the
account-owned operation lock for both agent commands and the root backup job.
Home creation and unmount
hold the same root-only lock. A concurrent start waits up to five minutes,
then checks the
mounted image left by the first or fails without touching its candidate.

Lock acquisition is limited to five minutes. Allocation has ten minutes,
formatting five, each fsck twenty, and mount and unmount two minutes each.
Filesystem probes have thirty seconds; runtime and cgroup setup each have one
minute. The allocation and format bounds allow slow host metadata work, the
fsck bound permits a populated 256 GiB image, and the short probe, mount and
unmount bounds prevent routine kernel operations from extending shutdown.
A timed-out command's process group receives KILL at its deadline, including
descendants that could retain the lock. First creation has at most 43 minutes
of external-command waits. The home stop action has eleven minutes of
configured waits: five for its lock, three for Podman's graceful stop, one for
cgroup drain and two for unmount. The full stop chain has forty-two minutes:
Compose's thirty-minute helper grace and one-minute service drain, followed
by the eleven-minute home action. These bounds exclude an already-running
start. Podman gets ten seconds per container within its three-minute
total bound; an incomplete stop falls through to the forced drain. Agent
startup gives state reconciliation one minute. A drain writes
to the root-owned =cgroup.kill= file under the delegated subtree and waits at
most one minute
for =cgroup.events= to report =populated 0=. At deadline it reports remaining
PIDs and leaves the home mounted. The same bound applies to Compose's service
subtree drain after its helper exits. Once empty, the drain removes descendant
cgroup directories, including Podman's runtime cgroup and stale SSH leaves;
the delegated and service roots remain for the next start. Populated leaves
remain untouched.
Runtime and cgroup setup each add at most one minute. A busy unmount can
leave Shepherd showing the home stopped while =findmnt /home/aiagent= still
shows it mounted. The operator must clear the users of that mount, start
=aiagent-home= to restore Shepherd's running record, and stop it again to
retry the unmount; =findmnt= is the mount-state check.
Formatting preserves the image's allocated blocks, and each start validates
the reservation. First creation requires 128 GiB of free host space beyond
the 256 GiB image so operator services retain working room during allocation.
Ext4 inode tables and the journal are initialized during formatting, so the
kernel has no lazy initialization work that can release backing-file extents
after mounting. An existing image with holes is re-reserved with ordinary
=fallocate=, which leaves existing data intact. Its headroom check covers only
the missing allocated bytes plus the 128 GiB host reserve.
Service and SSH launch paths select Guix's privileged
UID/GID-mapping wrappers before profile binaries.
The root launcher clears supplementary groups with Guile's vector interface,
then sets the private GID and UID before executing agent-owned code.

The host account retains tailscaled's non-operator read-only local API access;
the Guix module does not change its socket. The agent container must exclude
host runtime paths, including the Tailscale socket.

The module lives below the Guix configuration load path. Ansible supplies
authorized public keys when it selects the service. Removing that service
removes the account, sub-ID declaration and host services together.

(define aiagent-home-locked-program
  (program-file
   "aiagent-home"
   #~(begin
       (use-modules (ice-9 popen) (ice-9 rdelim))
       (define (timed-status seconds . command)
         (let* ((status (apply system* #$(file-append coreutils "/bin/timeout")
                               "--signal=KILL" (number->string seconds)
                               command))
                (exit (status:exit-val status)))
           (if (number? exit) exit 137)))
       (define (run seconds . command)
         (unless (zero? (apply timed-status seconds command))
           (error "aiagent home command failed" command)))
       (define (directory path mode)
         (unless (file-exists? path) (mkdir path mode))
         (chmod path mode))
       (define (validate-image path)
         (let ((metadata (stat path)))
           (unless (= (stat:size metadata) #$%image-size-bytes)
             (error "aiagent image has unexpected size"))
           (unless (>= (* 512 (stat:blocks metadata))
                       #$%image-size-bytes)
             (error "aiagent image is not fully allocated"))
           (unless (= (stat:uid metadata) 0)
             (error "aiagent image is not root-owned"))
           (chmod path #o600)))
       (define (available-host-bytes)
         (let* ((port (open-pipe* OPEN_READ
                                  #$(file-append coreutils "/bin/timeout")
                                  "--signal=KILL"
                                  #$(number->string %home-probe-seconds)
                                  #$(file-append coreutils "/bin/stat")
                                  "-f" "-c" "%a %S" "/var/lib/aiagent"))
                (blocks (read port))
                (block-size (read port))
                (status (close-pipe port)))
           (unless (and (equal? (status:exit-val status) 0)
                        (integer? blocks) (>= blocks 0)
                        (integer? block-size) (> block-size 0))
             (error "cannot measure host free space"))
           (* blocks block-size)))
       (define (reserve-existing-image)
         (let* ((metadata (stat #$%image))
                (allocated (* 512 (stat:blocks metadata)))
                (missing (max 0 (- #$%image-size-bytes allocated))))
           (unless (= (stat:size metadata) #$%image-size-bytes)
             (error "aiagent image has unexpected size"))
           (unless (= (stat:uid metadata) 0)
             (error "aiagent image is not root-owned"))
           (when (> missing 0)
             (unless (>= (available-host-bytes)
                         (+ missing #$%host-free-reserve-bytes))
               (error "insufficient host free space to restore aiagent image allocation"))
             (run #$%home-allocation-seconds
                  #$(file-append util-linux "/bin/fallocate")
                  "-l" (number->string #$%image-size-bytes) #$%image))))
       (directory "/var/lib/aiagent" #o700)
       (let ((mounted-status
              (timed-status #$%home-probe-seconds
                            #$(file-append util-linux "/bin/mountpoint")
                            "-q" #$%home)))
         (cond
          ((zero? mounted-status)
           (let* ((port (open-pipe* OPEN_READ
                                    #$(file-append coreutils "/bin/timeout")
                                    "--signal=KILL"
                                    #$(number->string %home-probe-seconds)
                                    #$(file-append util-linux "/bin/findmnt")
                                    "-n" "-o" "SOURCE" "--mountpoint" #$%home))
                  (source (read-line port))
                  (status (close-pipe port)))
             (unless (and (equal? (status:exit-val status) 0)
                          (string? source)
                          (> (string-length source) 9)
                          (string=? (substring source 0 9) "/dev/loop")
                          (string=?
                           (call-with-input-file
                               (string-append "/sys/block/"
                                              (substring source 5)
                                              "/loop/backing_file")
                             read-line)
                           #$%image))
               (error "aiagent home is mounted from another source")))
           (reserve-existing-image)
           (validate-image #$%image))
          ((member mounted-status '(1 32))
           (directory #$%home #o000)
           (let ((created? #f))
             (unless (file-exists? #$%image)
               (let ((candidate (string-append #$%image ".new")))
                 (when (file-exists? candidate) (delete-file candidate))
                 (unless (>= (available-host-bytes)
                             (+ #$%image-size-bytes
                                #$%host-free-reserve-bytes))
                   (error "insufficient host free space for aiagent image and reserve"))
                 (dynamic-wind
                   (lambda () #t)
                   (lambda ()
                     (run #$%home-allocation-seconds
                          #$(file-append util-linux "/bin/fallocate")
                          "-l" (number->string #$%image-size-bytes) candidate)
                     (chmod candidate #o600)
                     (run #$%home-format-seconds
                          #$(file-append e2fsprogs "/sbin/mkfs.ext4")
                          "-F" "-E"
                          "nodiscard,lazy_itable_init=0,lazy_journal_init=0"
                          candidate)
                     (validate-image candidate)
                     (let ((status
                            (timed-status #$%home-fsck-seconds
                                          #$(file-append e2fsprogs "/sbin/e2fsck")
                                          "-p" candidate)))
                       (unless (member status '(0 1))
                         (error "aiagent candidate failed fsck" status)))
                     (rename-file candidate #$%image))
                   (lambda ()
                     (when (file-exists? candidate)
                       (delete-file candidate)))))
               (set! created? #t))
             (unless created?
               (reserve-existing-image))
             (validate-image #$%image)
             (unless created?
               (let ((status (timed-status #$%home-fsck-seconds
                                           #$(file-append e2fsprogs "/sbin/e2fsck")
                                           "-p" #$%image)))
                 (unless (member status '(0 1))
                   (error "aiagent image failed fsck" status))))
             (run #$%home-mount-seconds
                  #$(file-append util-linux "/bin/mount")
                  "-o" "loop,nodev,nosuid" #$%image #$%home)))
          (else (error "cannot inspect aiagent home mount")))
         (let ((account (getpwnam "aiagent")))
           (chown #$%home (passwd:uid account) (passwd:gid account)))
         (chmod #$%home #o700)))))

(define aiagent-cgroup-drain-program
  (program-file
   "aiagent-cgroup-drain"
   #~(begin
       (use-modules (ice-9 ftw))
       (define target
         (cond ((equal? (cdr (command-line)) '("all")) #$%delegated)
               ((equal? (cdr (command-line)) '("service"))
                (string-append #$%delegated "/service"))
               (else (error "invalid aiagent cgroup drain target"))))
       (define (uptime-seconds)
         (call-with-input-file "/proc/uptime" read))
       (define (populated? directory)
         (call-with-input-file (string-append directory "/cgroup.events")
           (lambda (port)
             (let loop ((name (read port)))
               (when (eof-object? name)
                 (error "aiagent cgroup.events has no populated field"))
               (let ((value (read port)))
                 (if (eq? name 'populated)
                     (case value
                       ((0) #f)
                       ((1) #t)
                       (else (error "invalid aiagent cgroup populated value" value)))
                     (loop (read port))))))))
       (define (remaining-pids directory)
         (catch 'system-error
           (lambda ()
             (append
              (call-with-input-file
                  (string-append directory "/cgroup.procs")
                (lambda (port)
                  (let loop ((pid (read port)))
                    (if (eof-object? pid) '()
                        (cons pid (loop (read port)))))))
              (apply append
                     (map (lambda (name)
                            (let ((child (string-append directory "/" name)))
                              (catch 'system-error
                                (lambda ()
                                  (if (eq? (stat:type (stat child)) 'directory)
                                      (remaining-pids child)
                                      '()))
                                (lambda _ '()))))
                          (scandir directory
                                   (lambda (name)
                                     (not (member name '("." "..")))))))))
           (lambda _ '())))
       (define (remove-empty-descendants directory)
         (for-each
          (lambda (name)
            (let ((child (string-append directory "/" name)))
              (when (catch 'system-error
                      (lambda () (eq? (stat:type (stat child)) 'directory))
                      (lambda _ #f))
                (remove-empty-descendants child)
                (unless (or (string=? child
                                     (string-append #$%delegated "/service"))
                            (populated? child))
                  (rmdir child)))))
          (scandir directory
                   (lambda (name) (not (member name '("." "..")))))))
       (unless (= (geteuid) 0)
         (error "aiagent cgroup drain requires root"))
       (call-with-output-file (string-append target "/cgroup.kill")
         (lambda (port) (display "1" port)))
       (let ((deadline (+ (uptime-seconds) #$%cgroup-drain-seconds)))
         (let loop ()
           (when (populated? target)
             (if (>= (uptime-seconds) deadline)
                 (error "aiagent cgroup remains populated; remaining PIDs"
                        (remaining-pids target))
                 (begin
                   (sleep #$%cgroup-drain-poll-seconds)
                   (loop)))))
       (remove-empty-descendants target)
       (when (populated? target)
         (error "aiagent cgroup repopulated during cleanup; remaining PIDs"
                (remaining-pids target)))))))

(define aiagent-cgroup-program
  (program-file
   "aiagent-cgroup"
   #~(begin
       (define (write path value)
         (call-with-output-file path (lambda (port) (display value port))))
       (define (ensure path)
         (unless (zero? (system* #$(file-append coreutils "/bin/mkdir")
                                  "-p" path))
           (error "cannot create aiagent cgroup" path)))
       (ensure #$%cgroup)
       (write (string-append #$%cgroup "/cpu.max") "400000 100000")
       (write (string-append #$%cgroup "/cpu.weight") "50")
       (write (string-append #$%cgroup "/memory.max")
              (number->string (* 12 1024 1024 1024)))
       (write (string-append #$%cgroup "/memory.high")
              (number->string (* 10 1024 1024 1024)))
       (write (string-append #$%cgroup "/pids.max") "4096")
       (write (string-append #$%cgroup "/cgroup.subtree_control")
              "+cpu +memory +pids")
       (ensure #$%delegated)
       (write (string-append #$%delegated "/cgroup.subtree_control")
              "+cpu +memory +pids")
       (let* ((account (getpwnam "aiagent"))
              (uid (passwd:uid account))
              (gid (passwd:gid account)))
         (chown #$%delegated uid gid)
         (for-each (lambda (name)
                     (chown (string-append #$%delegated "/" name)
                            uid gid))
                   '("cgroup.procs" "cgroup.threads"
                     "cgroup.subtree_control"))
         (ensure (string-append #$%delegated "/service"))
         (chown (string-append #$%delegated "/service") uid gid)
         (chown (string-append #$%delegated "/service/cgroup.procs")
                uid gid)))))

(define (aiagent-shepherd-services _)
  (list
   (shepherd-service
   (provision '(aiagent-home))
    (requirement '(user-processes))
    (start #~(lambda _ (zero? (system* #$aiagent-home-program))))
    (stop #~(lambda _
              (define (remaining-pids directory)
                (catch 'system-error
                  (lambda ()
                    (append
                     (call-with-input-file
                         (string-append directory "/cgroup.procs")
                       (lambda (port)
                         (let loop ((pid (read port)))
                           (if (eof-object? pid) '()
                               (cons pid (loop (read port)))))))
                     (apply append
                            (map (lambda (name)
                                   (let ((child (string-append directory "/" name)))
                                     (catch 'system-error
                                       (lambda ()
                                         (if (eq? (stat:type (stat child))
                                                  'directory)
                                             (remaining-pids child)
                                             '()))
                                       (lambda _ '()))))
                                 ((@ (ice-9 ftw) scandir) directory
                                  (lambda (name)
                                    (not (member name '("." "..")))))))))
                  (lambda _ '())))
              (if (zero? (system* #$aiagent-home-stop-program))
                  #f
                  (error "aiagent home may remain mounted; check findmnt; remaining delegated PIDs"
                         (remaining-pids #$%delegated)))))
    (respawn? #f))
   (shepherd-service
    (provision '(aiagent-runtime))
    (requirement '(user-processes))
    (one-shot? #t)
    (start #~(lambda _

* Git hub

The Git hub has its own =agentgit= account and private group. Its home at
=/var/lib/agentgit= holds Gitolite's repositories and administrative state.
Only an operator public key initializes Gitolite; repository and agent key
policy is committed through =gitolite-admin=. The account is independent of
the =aiagent= service and has no subordinate ID range or access to the agent's
home. Gitolite's private umask and the account's private group keep its home
and repositories unreadable by =aiagent=.

Every push through this account is bounded by Git's =receive.maxInputSize=,
which rejects an incoming pack stream above the configured byte count before
refs are updated. Git's object integrity check also runs on received objects.
The limit covers both operators and agents; it is a compressed pack limit, so
it is not a quota on the resulting repository size.

The Gitolite receive command holds the root-owned shared lock until
=git-receive-pack= and Gitolite's administrative hooks finish. The receive
process inherits the descriptor across exec, so the lock survives death of
the Gitolite parent. A completed receive releases it without retaining an
unrelated detached hook process. The lock directory is root-owned and cannot
be renamed by =agentgit=. Root backup
checks the directory and file ownership before waiting on the same inode.
It waits at most five minutes for an active receive, then fails without a hub
snapshot and follows the existing agent service recovery path.
The trigger code is installed under root-controlled =/etc/git-hub=; it is not
loaded from the Gitolite administrative repository or another writable path.

package Gitolite::Triggers::HubLock;
use strict;
use warnings;
use Fcntl qw(:flock :DEFAULT F_GETFD F_SETFD FD_CLOEXEC);

my $held;
my $config_slot;
my $directory = '/var/lib/agentgit-lock';
my $path = "$directory/receive.lock";

sub pre_git {
    my ($section, $repo, $user, $access, $ref, $verb) = @_;
    return unless $verb eq 'git-receive-pack';
    my ($gid) = split /\s+/, $);
    my @directory_stat = lstat($directory);
    die "unsafe Git hub lock directory\n"
        unless @directory_stat && -d _ && $directory_stat[4] == 0
        && $directory_stat[5] == $gid && ($directory_stat[2] & 07777) == 0750;
    sysopen(my $handle, $path, O_RDWR | O_NOFOLLOW)
        or die "cannot open Git hub lock\n";
    my $flags = fcntl($handle, F_GETFD, 0);
    die "cannot inspect Git hub lock descriptor\n" unless defined $flags;
    fcntl($handle, F_SETFD, $flags & ~FD_CLOEXEC)
        or die "cannot pass Git hub lock to receive-pack\n";
    my @file_stat = stat($handle);
    die "unsafe Git hub lock file\n"
        unless @file_stat && -f _ && $file_stat[4] == 0
        && $file_stat[5] == $gid && ($file_stat[2] & 07777) == 0660;
    flock($handle, LOCK_EX) or die "cannot lock Git hub\n";
    $held = $handle;
    my $count = $ENV{GIT_CONFIG_COUNT} // 0;
    die "invalid Git config count\n" unless $count =~ /^\d+$/ && $count < 32;
    $config_slot = $count;
    $ENV{"GIT_CONFIG_KEY_$count"} = 'core.hooksPath';
    $ENV{"GIT_CONFIG_VALUE_$count"} = '/etc/git-hub/hooks';
    $ENV{GIT_CONFIG_COUNT} = $count + 1;
    $ENV{GAK_HUB_CONFIG_BASE} = $count;
    $ENV{GAK_HUB_LOCK_FD} = fileno($handle);
}

sub post_git {
    close($held) if $held;
    undef $held;
    if (defined $config_slot) {
        $ENV{GIT_CONFIG_COUNT} = $config_slot;
        delete $ENV{"GIT_CONFIG_KEY_$config_slot"};
        delete $ENV{"GIT_CONFIG_VALUE_$config_slot"};
        undef $config_slot;
    }
    delete $ENV{GAK_HUB_CONFIG_BASE};
    delete $ENV{GAK_HUB_LOCK_FD};
}

1;

Each receive hook enters a root-controlled wrapper that holds the descriptor
while its original repository hook runs. The wrapper closes the descriptor in
the hook child before exec, so a detached child cannot extend the lock past
the completed receive. The original Gitolite hooks still enforce ref policy
and update the administrative repository.

The root mcron jobs use a store-captured program and a root-owned Restic
password file at =/etc/aiagent/restic-password=. They write encrypted snapshots
to =/marak/backups/aiagent/restic=. The daily job stops the Compose service

password and repository are outside the agent's mounted home and container.

The minute job creates its result under root-owned =/run/aiagent-backup= and
atomically hands the finished file to the account. Daily backup and restore
check take the account's operation lock and reject a surviving foreground
operation session recorded under =/run/aiagent=, including Compose children that
outlive their worker. Detached workloads leave that session and do not hold the
exclusion. The jobs attempt service recovery even when stopping Compose
fails; the stop deadline covers the documented service and home stop chain.
Termination signals settle the current command's process group before a
bounded recovery of the home mount and Compose service. Further signals during
recovery do not release the operation lock early. The handler records the
request; command waits check it at bounded intervals, and recovery performs no
asynchronous interruption checks.
Seven daily, five weekly and twelve monthly snapshots are retained. A restore
check takes a fresh snapshot into root-controlled scratch on the backup disk,
compares every regular file by checksum and removes the scratch tree.
When =agentgit= exists, the same snapshot includes complete bundles of
=gitolite-admin= and initialized =arc= refs. Gitolite receives and the backup
share one lock from before the first bundle through Restic snapshot creation,

scratch. A restore check imports each bundle into a temporary bare repository

Git's full object check, and reconstructs the administrative policy and key

beside the bundles for independent recovery. Root never runs Git against
hub-controlled repositories or hooks. The temporary imports live under a
root-owned parent with a private child

repository is created by Gitolite policy and has no bundle to import.

def stop_process(process):
    try:
        os.killpg(process.pid, signal.SIGTERM)
    except ProcessLookupError:
        pass
    deadline = time.monotonic() + 10
    while time.monotonic() < deadline:
        process.poll()
        try:
            os.killpg(process.pid, 0)
        except ProcessLookupError:
            break
        time.sleep(0.05)
    else:
        try:
            os.killpg(process.pid, signal.SIGKILL)
        except ProcessLookupError:
            pass
    try:
        process.communicate(timeout=5)
    except subprocess.TimeoutExpired:
        try:
            os.killpg(process.pid, signal.SIGKILL)
        except ProcessLookupError:
            pass
        process.wait(timeout=5)


def run_process(arguments, *, check=False, timeout=None, env=None,
                stdin=None, stdout=None, stderr=None, capture_output=False, text=False,
                cwd=None,
                ignore_interrupt=False, user=None, group=None, extra_groups=None):
    if not ignore_interrupt:
        check_interrupted()
    process = subprocess.Popen(
        arguments, env=env, stdin=stdin,
        stdout=subprocess.PIPE if capture_output else stdout,
        stderr=subprocess.PIPE if capture_output else stderr,
        text=text, cwd=cwd, start_new_session=True, user=user, group=group,
        extra_groups=extra_groups,
    )
    deadline = None if timeout is None else time.monotonic() + timeout
    try:
        while True:
            if not ignore_interrupt:
                check_interrupted()
            remaining = None if deadline is None else deadline - time.monotonic()
            if remaining is not None and remaining <= 0:
                raise subprocess.TimeoutExpired(arguments, timeout)
            interval = 0.2 if remaining is None else min(0.2, remaining)
            try:
                output, errors = process.communicate(timeout=interval)
                break
            except subprocess.TimeoutExpired:
                continue
        if not ignore_interrupt:
            check_interrupted()
    except (Interrupted, subprocess.TimeoutExpired):
        stop_process(process)
        raise
    result = subprocess.CompletedProcess(arguments, process.returncode, output, errors)
    if check:
        result.check_returncode()
    return result

            try:
                repo = source.lstat()
            except FileNotFoundError:
                if name == "arc":
                    continue
                raise RuntimeError("Git hub administration repository is missing") from None
            if not stat.S_ISDIR(repo.st_mode) or repo.st_uid != account.pw_uid:
                raise RuntimeError("unsafe Git hub repository")
            refs, head = hub_refs(account, environment, source)
            if not refs:
                if name == "arc":
                    continue
                raise RuntimeError("Git hub administration repository is empty")
            destination = scratch / f"{name}.bundle"
            descriptor = os.open(destination, os.O_WRONLY | os.O_CREAT | os.O_EXCL | NOFOLLOW, 0o600)
            try:
                hub_git(account, environment,
                        ("-C", str(source), "bundle", "create", "-", "--all"),
                        stdout=descriptor)
                os.fsync(descriptor)
            finally:
                os.close(descriptor)
            expected[name] = {"digest": digest_file(destination),
                              "refs": refs, "head": head}
        verify_bundles(scratch, expected, admin_files, account)
        recorded = {"repos": expected, "admin_files": admin_files}
        manifest_file = scratch / "manifest.json"
        descriptor = os.open(manifest_file, os.O_WRONLY | os.O_CREAT | os.O_EXCL | NOFOLLOW, 0o600)
        with os.fdopen(descriptor, "w") as output:
            json.dump(recorded, output, sort_keys=True)
            output.flush()
            os.fsync(output.fileno())
        return scratch, recorded
    except BaseException:
        shutil.rmtree(scratch)
        raise


def snapshot():
    validate_password()
    if run_process(("findmnt", "-n", "--mountpoint", str(HOME)),
                   stdout=subprocess.DEVNULL, stderr=subprocess.DEVNULL).returncode:
        raise RuntimeError("agent home is not mounted")
    root_directory(BACKUP_ROOT, create=True)
    root_directory(REPOSITORY, create=True)
    environment = dict(os.environ, RESTIC_REPOSITORY=str(REPOSITORY),
                       RESTIC_PASSWORD_FILE=str(PASSWORD))

    def restic(*arguments, quiet=True):
        argv = ["restic", *arguments]
        if quiet:
            argv.insert(1, "--quiet")
        run_process(argv, check=True, env=environment)

    with hub_exclusion():
        bundles, expected = hub_bundles()
        try:
            if not (REPOSITORY / "config").is_file():
                restic("init")
            sources = [str(HOME / "workspaces"), str(HOME / "container-home")]
            if bundles is not None:
                sources.append(str(bundles))
            restic("backup", "--host", "gak", "--tag", "aiagent", *sources)
        finally:
            if bundles is not None:
                shutil.rmtree(bundles)
    restic("forget", "--host", "gak", "--tag", "aiagent",
           "--keep-daily", "7", "--keep-weekly", "5", "--keep-monthly", "12", "--prune")
    restic("check")
    return environment, bundles, expected


def process_identity(pid):
    try:
        fields = Path(f"/proc/{pid}/stat").read_text().rsplit(")", 1)[1].split()
    except FileNotFoundError:
        return None
    if fields[0] in ("Z", "X"):
        return None
    return fields[19]


def process_session_active(pid, started):
    identity = process_identity(pid)
    if identity is not None:
        return identity == started
    for entry in Path("/proc").iterdir():
        if not entry.name.isdecimal():
            continue
        try:
            fields = (entry / "stat").read_text().rsplit(")", 1)[1].split()
        except OSError:
            continue
        if fields[0] not in ("Z", "X") and fields[3] == str(pid):
            return True
    return False


def active_operation():
    try:
        descriptor, _ = secure_file(RUNTIME / "aiagent.active", os.O_RDONLY, agent_account().pw_uid)
    except FileNotFoundError:
        return False
    try:
        payload = os.read(descriptor, 4097)
    finally:
        os.close(descriptor)
    if len(payload) > 4096:
        raise Busy("agent operation record is too large")
    try:
        record = json.loads(payload)
        pid, started = record["pid"], record["start"]
        if not isinstance(pid, int) or pid < 1 or not isinstance(started, str):
            raise ValueError()
    except (ValueError, KeyError, TypeError):
        raise Busy("agent operation record is invalid") from None
    return process_session_active(pid, started)


def operation_lock():
    descriptor, _ = secure_file(RUNTIME / "aiagent.lock", os.O_RDONLY, agent_account().pw_uid)
    try:
        try:
            fcntl.flock(descriptor, fcntl.LOCK_EX | fcntl.LOCK_NB)
        except BlockingIOError:
            raise Busy("an agent operation holds the lock") from None
        if active_operation():
            raise Busy("an agent operation worker is still running")
        return descriptor
    except BaseException:
        os.close(descriptor)
        raise


def read_request():
    path = RUNTIME / "backup-request"
    try:
        descriptor, metadata = secure_file(path, os.O_RDONLY, agent_account().pw_uid)
    except FileNotFoundError:
        return None
    try:
        if stat.S_IMODE(metadata.st_mode) != 0o600:
            raise RuntimeError("unsafe backup request mode")
        payload = os.read(descriptor, 129)
        if len(payload) > 128:
            raise RuntimeError("backup request is too large")
    finally:
        os.close(descriptor)
    try:
        nonce = payload.decode("ascii").strip()
    except UnicodeDecodeError:
        raise RuntimeError("invalid backup request") from None
    if re.fullmatch(r"[0-9]+-[0-9]+", nonce) is None:
        raise RuntimeError("invalid backup request")
    return nonce, (metadata.st_dev, metadata.st_ino)


def publish_result(nonce, outcome):
    account = agent_account()
    for _ in range(10):
        temporary = RESULT_ROOT / f"result.{secrets.token_hex(12)}"
        try:
            descriptor = os.open(temporary, os.O_WRONLY | os.O_CREAT | os.O_EXCL | NOFOLLOW, 0o600)
            break
        except FileExistsError:
            continue
    else:
        raise RuntimeError("cannot reserve backup result")
    try:
        payload = memoryview(f"{outcome} {nonce}\n".encode())
        while payload:
            payload = payload[os.write(descriptor, payload):]
        os.fchown(descriptor, account.pw_uid, account.pw_gid)
        os.fsync(descriptor)
    except BaseException:
        temporary.unlink(missing_ok=True)
        raise
    finally:
        os.close(descriptor)
    try:
        os.replace(temporary, RUNTIME / "backup-result")
    except BaseException:
        temporary.unlink(missing_ok=True)
        raise


def request():
    received = read_request()
    if received is None:
        return
    nonce, identity = received
    failure = None
    try:
        snapshot()
    except Exception as error:
        failure = error
    publish_result(nonce, "failed" if failure else "ok")
    try:
        current = (RUNTIME / "backup-request").lstat()
        if (current.st_dev, current.st_ino) == identity:
            (RUNTIME / "backup-request").unlink()
    except FileNotFoundError:
        pass
    if failure:
        raise failure


def recover_service():
    deadline = time.monotonic() + RECOVERY_TIMEOUT

    def bound(limit):
        remaining = deadline - time.monotonic()
        if remaining <= 0:
            raise RuntimeError("agent Compose recovery deadline expired")
        return min(limit, remaining)

    def start(service, limit):
        for attempt in range(2):
            try:
                started = run_process(("herd", "start", service), timeout=bound(limit),
                                      ignore_interrupt=True)
                status = started.returncode
            except subprocess.TimeoutExpired:
                status = 124
            if status == 0:
                return
            if attempt == 0:
                try:
                    run_process(("herd", "enable", service), timeout=bound(START_TIMEOUT),
                                ignore_interrupt=True)
                except subprocess.TimeoutExpired:
                    pass
        raise RuntimeError(f"agent service did not restart: {service}")

    def mounted():
        return run_process(("findmnt", "-n", "--mountpoint", str(HOME)),
                           timeout=bound(30), stdout=subprocess.DEVNULL,
                           stderr=subprocess.DEVNULL, ignore_interrupt=True).returncode == 0

    if not mounted():
        start("aiagent-home", HOME_START_TIMEOUT)
        if not mounted():
            raise RuntimeError("agent home did not remount")
    try:
        start(SERVICE, START_TIMEOUT)
    except RuntimeError:
        start("aiagent-home", HOME_START_TIMEOUT)
        if not mounted():
            raise RuntimeError("agent home did not remount") from None
        start(SERVICE, START_TIMEOUT)


def quiesced(action):
    with signal_guard():
        try:
            check_interrupted()
            command("herd", "stop", SERVICE, timeout=STOP_TIMEOUT)
            check_interrupted()
            action()
            check_interrupted()
        finally:
            recover_service()
        check_interrupted()


def manifest(root, names=("workspaces", "container-home")):
    entries = {}

    def visit(path):
        check_interrupted()
        metadata = path.lstat()
        relative = str(path.relative_to(root))
        if stat.S_ISLNK(metadata.st_mode):
            entries[relative] = ("link", os.readlink(path))
        elif stat.S_ISDIR(metadata.st_mode):
            entries[relative] = ("directory",)
            for child in sorted(path.iterdir()):
                visit(child)
        elif stat.S_ISREG(metadata.st_mode):
            digest = hashlib.sha256()
            descriptor, _ = secure_file(path, os.O_RDONLY)
            with os.fdopen(descriptor, "rb") as source:
                for chunk in iter(lambda: source.read(1024 * 1024), b""):
                    check_interrupted()
                    digest.update(chunk)
            entries[relative] = ("file", digest.hexdigest())
        else:
            entries[relative] = ("special", stat.S_IFMT(metadata.st_mode))

    for name in names:
        visit(root / name)
    return entries


def restore_check():

def run_operation(operation):
    if os.geteuid() != 0:
        raise RuntimeError("agent backup requires root")
    os.environ["PATH"] = "/run/current-system/profile/bin:/run/privileged/bin:/usr/bin:/bin"
    root_directory(STATE)
    root_directory(RESULT_ROOT, create=True)
    descriptor = os.open(STATE / "backup.lock", os.O_RDWR | os.O_CREAT | NOFOLLOW, 0o600)
    try:
        try:
            fcntl.flock(descriptor, fcntl.LOCK_EX | fcntl.LOCK_NB)
        except BlockingIOError:
            raise Busy("another backup is running") from None
        if operation == "request":
            request()
        elif operation in ("daily", "restore-check"):
            validate_password()
            operation_descriptor = operation_lock()
            try:
                quiesced(snapshot if operation == "daily" else restore_check)
            finally:
                os.close(operation_descriptor)
        else:
            raise RuntimeError("usage: backup.py {request|daily|restore-check}")
    finally:
        os.close(descriptor)

* Gak container image

The Fedora 44 image installs the harness executables under =/usr/local=. The
container mounts only its persistent home, workspaces and cache, all from the
agent's image-backed host home. The image's executable paths remain visible
when the persistent home is mounted. The container has no host runtime, socket,
media or operator-home mount. Podman's =keep-id= mapping makes the agent's host
directories writable by the container user.

The harness versions are fixed at build time. Pi uses the pinned upstream
Node executable under =/opt/pi-node= for its interactive TUI and print mode;
the Fedora Node installation serves npm and the other harnesses. Pi's =/login=
menu runs inside the container. Logins and provider state live under the
persistent home. The cache subtree is disposable;
the =aiagent= command reports its size and cleans only that subtree on request.
Image-installed commands under =/usr/local/bin= take precedence over programs
left in the persistent home.
T3 Code v0.0.42 runs in web mode on the container's port 3773. The image's
foreground supervisor owns the native server process and restarts it two
seconds after an exit. T3's process is
separate from terminal sessions, and a container start launches the supervisor
without a host-side exec. Podman publishes container port 3773 only on host
loopback. The shared =gak_t3_port= inventory value selects that host port and
the Tailscale backend port; host Tailscale owns HTTPS ingress. T3's pairing
state stays in the persistent container home.

** Container command wrappers

These wrappers are installed with the image, so rebuilding the container does
not depend on replacing files in the persistent home. The =pi= wrapper selects
the upstream Node executable while the other harness commands keep the Fedora
runtime.

The readiness command lives in the image. Both a disposable candidate and the
running project execute the same entry point and executable search path. It
requires the native T3 executable, image-owned Pi wrapper and the
three persistent mount points without reading login state. Candidate readiness
starts the native server against temporary state on container loopback and
requires an HTTP response before stopping it. Running-project readiness
requires the supervised server to answer on its container port, so a failing
persistent T3 state cannot pass the update gate.

#+begin_src python :tangle (expand-file-name "roles/gak_aiagent/files/image/bin/aiagent-readiness" (file-name-directory (buffer-file-name))) :mkdirp yes :shebang #!/usr/bin/env python3 :tangle-mode o755
import http.client
import os

PORT = 3773


def require_image():
    os.environ["PATH"] = "/usr/local/bin:/usr/bin:/bin"
    for directory in ("/home/node", "/work", "/cache"):
        if not Path(directory).is_dir():
            raise RuntimeError(f"missing mount point: {directory}")
    for tool in ("codex", "claude", "opencode", "t3", "pi"):
        if shutil.which(tool) is None:
            raise RuntimeError(f"missing image command: {tool}")
    if not os.access("/usr/local/bin/t3-native", os.X_OK):
        raise RuntimeError("missing native T3 server")
    if shutil.which("pi") != "/usr/local/bin/pi":
        raise RuntimeError("Pi does not resolve to the image wrapper")


def serving(port):
    connection = http.client.HTTPConnection("127.0.0.1", port, timeout=2)
    try:
        connection.request("GET", "/")
        response = connection.getresponse()
        return (response.status == 200
                and response.getheader("Content-Type", "").split(";", 1)[0] == "text/html"
                and bool(response.read(1)))
    finally:
        connection.close()


def candidate():
    with socket.socket() as listener:
        listener.bind(("127.0.0.1", 0))
        port = listener.getsockname()[1]
    with tempfile.TemporaryDirectory(prefix="t3-readiness-", dir="/cache/tmp") as state:
        server = subprocess.Popen(
            ["/usr/local/bin/t3-native", "serve", "--mode", "web",
             "--host", "127.0.0.1", "--port", str(port),
             "--base-dir", state, "--no-browser"],
            cwd="/work", stdout=subprocess.DEVNULL, stderr=subprocess.DEVNULL,
            start_new_session=True,
        )
        try:
            deadline = time.monotonic() + 30
            while time.monotonic() < deadline:
                if server.poll() is not None:
                    raise RuntimeError("candidate T3 server exited before serving")
                try:
                    if serving(port):
                        time.sleep(0.25)
                        if server.poll() is None and serving(port):
                            return
                except OSError:
                    pass
                time.sleep(0.25)
            raise RuntimeError("candidate T3 server did not serve HTTP")
        finally:
            try:
                os.killpg(server.pid, signal.SIGTERM)
            except ProcessLookupError:
                pass
            try:
                server.wait(timeout=5)
            except subprocess.TimeoutExpired:
                try:
                    os.killpg(server.pid, signal.SIGKILL)
                except ProcessLookupError:
                    pass
                server.wait()


def main():
    mode = sys.argv[1:] or ["--live"]
    if mode not in (["--live"], ["--candidate"]):
        raise RuntimeError("usage: aiagent-readiness [--live|--candidate]")
    require_image()
    if mode == ["--candidate"]:
        candidate()
    elif not serving(PORT):
        raise RuntimeError("supervised T3 server did not serve HTTP")

** Host command

The account-local command uses one lock for its mutating operations. The
foreground operation has a recorded process identity; a later caller waits for
its process session even if the caller or worker dies. The root backup job checks
the same record. Detached workloads leave the session and do not retain the
lock. Builds use the deployed context with all Podman and
temporary paths inside the image-backed home. The command does not alter
Shepherd, host ingress or other Compose instances. Cache cleanup removes only
the declared disposable cache subtree.
Restart stops and starts the Compose project in one recorded worker. This
releases the rootless port listener before the new container binds it and
keeps restart serialized if its invoking shell exits.

The lock helper records only a PID and kernel start time under =/run/aiagent=.
Its worker waits for that record before executing Podman. A dead caller closes
the worker's start gate; an operation that already started remains recorded
until its process exits. Project mutations move the worker into
=/sys/fs/cgroup/aiagent/delegated/service/cli= before executing Podman, so
long-lived project containers stay in the service subtree. An empty CLI leaf
is removed after the worker exits; a populated leaf stays until its container
stops or the home stop drains it. Cache cleanup runs in the lock holder itself.

#+begin_src python :tangle (expand-file-name "roles/gak_aiagent/files/aiagent-operation" (file-name-directory (buffer-file-name))) :mkdirp yes :shebang #!/usr/bin/env python3 :tangle-mode o750
import fcntl
import json
import os
from pathlib import Path
import shutil
import subprocess
import sys
import time


HOME = Path("/home/aiagent")
PODMAN = "/run/current-system/profile/bin/podman"
IMAGE = "localhost/aiagent-fedora:44-v1"
PROJECT = HOME / "services/agent/compose.yaml"
LOCK = Path("/run/aiagent/aiagent.lock")
ACTIVE = Path("/run/aiagent/aiagent.active")
PROJECT_CGROUP = Path("/sys/fs/cgroup/aiagent/delegated/service/cli")
GATE = """
import os
import sys
fd = int(sys.argv[1])
ready = os.read(fd, 1)
os.close(fd)
if ready != b'1':
    sys.exit(125)
leaf = sys.argv[2]
if leaf:
    os.makedirs(leaf, mode=0o700, exist_ok=True)
    with open(os.path.join(leaf, 'cgroup.procs'), 'w') as target:
        target.write(str(os.getpid()))
os.execv(sys.argv[3], sys.argv[3:])
"""
SEQUENCE = """
import json
import subprocess
import sys
for command in json.loads(sys.argv[1]):
    status = subprocess.run(command).returncode
    if status:
        sys.exit(status)
"""


def process_identity(pid):
    try:
        fields = Path(f"/proc/{pid}/stat").read_text().rsplit(")", 1)[1].split()
    except FileNotFoundError:
        return None
    if fields[0] in ("Z", "X"):
        return None
    return fields[19]


def process_session_active(pid, started):
    identity = process_identity(pid)
    if identity is not None:
        return identity == started
    for entry in Path("/proc").iterdir():
        if not entry.name.isdecimal():
            continue
        try:
            fields = (entry / "stat").read_text().rsplit(")", 1)[1].split()
        except OSError:
            continue
        if fields[0] not in ("Z", "X") and fields[3] == str(pid):
            return True
    return False


def wait_for_previous():
    if not ACTIVE.exists():
        return
    record = json.loads(ACTIVE.read_text())
    while process_session_active(record["pid"], record["start"]):
        time.sleep(0.1)
    ACTIVE.unlink()


def clean_project_cgroup():
    try:
        events = dict(line.split() for line in (PROJECT_CGROUP / "cgroup.events").read_text().splitlines())
        if events.get("populated") != "0":
            return
        for directory, children, _ in os.walk(PROJECT_CGROUP, topdown=False):
            for child in children:
                (Path(directory) / child).rmdir()
        PROJECT_CGROUP.rmdir()
    except (FileNotFoundError, OSError):
        pass


def run(command, project=False):
    read_fd, write_fd = os.pipe()
    worker = None
    recorded = False
    try:
        worker = subprocess.Popen(
            [sys.executable, "-c", GATE, str(read_fd),
             str(PROJECT_CGROUP) if project else "", *command],
            pass_fds=(read_fd,),
            start_new_session=True,
        )
        os.close(read_fd)
        read_fd = -1
        record = {"pid": worker.pid, "start": process_identity(worker.pid)}
        if record["start"] is None:
            raise RuntimeError("operation worker exited before startup")
        temporary = ACTIVE.with_name(f"{ACTIVE.name}.{os.getpid()}")
        temporary.write_text(json.dumps(record))
        os.replace(temporary, ACTIVE)
        recorded = True
        os.write(write_fd, b"1")
        return worker.wait()
    finally:
        if read_fd >= 0:
            os.close(read_fd)
        os.close(write_fd)
        if worker is not None and not recorded:
            worker.wait()
        settled = recorded and worker.poll() is not None and not process_session_active(
            record["pid"], record["start"])
        if settled:
            ACTIVE.unlink(missing_ok=True)
        if project and worker is not None and settled:
            clean_project_cgroup()


def cache_clean():
    cache = HOME / "cache"
    if not cache.is_dir() or cache.is_symlink():
        raise RuntimeError("cache directory is missing or linked")
    for entry in cache.iterdir():
        if entry.is_dir() and not entry.is_symlink():
            shutil.rmtree(entry)
        else:
            entry.unlink()
    for name in ("tmp", "npm", "xdg"):
        (cache / name).mkdir()


def command_for(operation):
    compose = [PODMAN, "compose", "-f", str(PROJECT)]
    if operation == "build":
        context = HOME / "image"
        if not (context / "Containerfile").is_file():
            raise RuntimeError("image context is not deployed")
        if subprocess.run([PODMAN, "image", "exists", IMAGE]).returncode == 0:
            raise RuntimeError(f"initial image already exists: {IMAGE}")
        return [PODMAN, "build", "--pull=missing", "--tag", IMAGE,
                "--file", str(context / "Containerfile"), str(context)]
    if operation == "update":
        return [str(HOME / ".local/bin/aiagent-update")]
    if operation == "start":
        if subprocess.run([PODMAN, "image", "exists", IMAGE]).returncode != 0:
            raise RuntimeError(f"local image is absent: {IMAGE}")
        return compose + ["up", "-d", "--pull", "never"]
    if operation == "stop":
        return compose + ["stop"]
    if operation == "restart":
        return [sys.executable, "-c", SEQUENCE,
                json.dumps([compose + ["stop"], compose + ["up", "-d", "--pull", "never"]])]
    if operation == "recreate":
        return compose + ["up", "-d", "--force-recreate", "--pull", "never"]
    raise RuntimeError(f"unknown operation: {operation}")


def main():
    if len(sys.argv) != 2:
        raise RuntimeError("expected one operation")
    with LOCK.open("a+") as lock:
        fcntl.flock(lock, fcntl.LOCK_EX)
        wait_for_previous()
        clean_project_cgroup()
        if sys.argv[1] == "cache-clean":
            cache_clean()
            return 0
        operation = sys.argv[1]
        return run(command_for(operation), project=operation in
                   {"start", "stop", "restart", "recreate", "update"})


if __name__ == "__main__":
    try:
        sys.exit(main())
    except (OSError, RuntimeError, ValueError, KeyError) as error:
        print(f"aiagent: {error}", file=sys.stderr)
        sys.exit(1)
#+end_src

An update builds a uniquely tagged candidate from the deployed context. Its
probe runs in a disposable container without persistent mounts or network
access. The live project is stopped before the root backup job snapshots its
workspaces and container home. The updater accepts the candidate's image ID
from the stopped project and runs the project's readiness command. A failure
before application starts the existing image again; a failed application keeps
both image IDs and the recovery snapshot for operator inspection. The failed
application reports the previous image's retention tag and the manual recovery
procedure in =GAK-SERVICES.org=.

#+begin_src python :tangle (expand-file-name "roles/gak_aiagent/files/aiagent-update" (file-name-directory (buffer-file-name))) :mkdirp yes :shebang #!/usr/bin/env python3 :tangle-mode o750
import hashlib
import os
from pathlib import Path
import subprocess
import sys
import time


HOME = Path("/home/aiagent")
PODMAN = "/run/current-system/profile/bin/podman"
UPDATER = HOME / ".guix-profile/bin/gak-services"
IMAGE = "localhost/aiagent-fedora:44-v1"
PROJECT = HOME / "services/agent/compose.yaml"
REQUEST = Path("/run/aiagent/backup-request")
RESULT = Path("/run/aiagent/backup-result")


def command(*argv, timeout=7200):
    result = subprocess.run(argv, timeout=timeout)
    if result.returncode:
        raise RuntimeError(f"command failed: {argv[1]}")


def image_id(reference):
    result = subprocess.run(
        [PODMAN, "image", "inspect", "--format", "{{.Id}}", reference],
        capture_output=True, text=True, timeout=60,
    )
    if result.returncode:
        raise RuntimeError("the local image is absent")
    return result.stdout.strip().removeprefix("sha256:")


def backup():
    nonce = f"{os.getpid()}-{time.monotonic_ns()}"
    RESULT.unlink(missing_ok=True)
    descriptor = os.open(REQUEST, os.O_CREAT | os.O_EXCL | os.O_WRONLY, 0o600)
    with os.fdopen(descriptor, "w") as request:
        request.write(nonce + "\n")
    try:
        deadline = time.monotonic() + 7200
        while time.monotonic() < deadline:
            try:
                response = RESULT.read_text().strip()
            except FileNotFoundError:
                time.sleep(1)
                continue
            if response == f"ok {nonce}":
                return
            if response == f"failed {nonce}":
                raise RuntimeError("the root backup job failed")
            time.sleep(1)
        raise RuntimeError("the root backup job did not answer within 7200 seconds")
    finally:
        REQUEST.unlink(missing_ok=True)
        RESULT.unlink(missing_ok=True)


def main():
    context = HOME / "image"
    if not (context / "Containerfile").is_file():
        raise RuntimeError("image context is not deployed")
    if not UPDATER.is_file():
        raise RuntimeError("the account's gak-services package is not installed")
    old = image_id(IMAGE)
    candidate = f"localhost/aiagent-fedora:44-candidate-{os.getpid()}-{time.monotonic_ns()}"
    built = False
    quiesced = False
    applying = False
    try:
        command(PODMAN, "build", "--pull=missing", "--tag", candidate,
                "--file", str(context / "Containerfile"), str(context))
        built = True
        candidate_id = image_id(candidate)
        command(PODMAN, "run", "--rm", "--network", "none", candidate_id,
                "/usr/local/bin/aiagent-readiness", "--candidate", timeout=180)
        command(PODMAN, "compose", "-f", str(PROJECT), "stop", timeout=180)
        quiesced = True
        backup()
        applying = True
        command(str(UPDATER), "update", "agent", "--from-stopped", "--force",
                "--prepared-image", f"agent={candidate_id}", timeout=900)
        if image_id(IMAGE) != candidate_id:
            raise RuntimeError("the accepted image reference moved")
        subprocess.run([PODMAN, "image", "rm", candidate], timeout=60)
        print(f"aiagent: accepted image {candidate_id[:12]}; previous image {old[:12]} is retained")
    except (OSError, RuntimeError, subprocess.TimeoutExpired):
        if quiesced and not applying:
            command(PODMAN, "compose", "-f", str(PROJECT), "up", "-d", "--pull", "never",
                    timeout=180)
        if built and not applying:
            subprocess.run([PODMAN, "image", "rm", candidate], timeout=60)
        if applying:
            pin = "localhost/gak-services-previous:" + hashlib.sha256(
                f"{PROJECT.parent.resolve()}:agent".encode()).hexdigest()[:24]
            try:
                retained = image_id(pin) == old
            except (OSError, RuntimeError, subprocess.TimeoutExpired):
                retained = False
            location = f"retained at {pin}" if retained else f"expected at {pin}; verify the pin"
            print(f"aiagent: previous image {old[:12]} {location}; see GAK-SERVICES.org "
                  "for manual rollback after inspecting the backup and state", file=sys.stderr)
        raise


if __name__ == "__main__":
    try:
        main()
    except (OSError, RuntimeError, subprocess.TimeoutExpired) as error:
        print(f"aiagent: update failed: {error}", file=sys.stderr)
        sys.exit(1)

* Harness notes

This role builds one persistent rootless Podman container for terminal-first AI
coding harnesses. The isolation boundary is the container plus agent
permissions; the host only shares =/work= and the explicitly mounted state
directories.

- =opencode= is a terminal coding agent with its own config/state.
- =codex= is OpenAI's terminal coding agent. In this container it edits and runs
  commands against the mounted =/work= tree, not the host filesystem in
  general. Codex still has its own sandbox/approval layer; the wrapper
  =codex-auto= starts it in workspace-write/on-request mode.
- Codex-compatible skills such as Impeccable should persist under
  =~/.agents/skills=. Mount the whole =~/.agents= tree rather than only the
  =skills= subdir so future agent config and metadata survive rebuilds too.
- =pi= remains installed but dormant. Print mode works, but the interactive TUI
  currently segfaults in this Fedora 44 container stack, so use host =pi= for
  Pi TUI work and keep container Pi only for explicit print-mode testing.
- =codex-auto=, =t3-web=, and =pi-readonly= are container-internal wrappers
  installed into =/home/node/.bin=. They are not host commands by themselves.
  Host shell functions below are prefixed with =aiagent-= and call them through
  =machinectl= and =podman exec=.
- T3 should run inside the existing harness container, not as a separate
  sidecar container. It wraps =codex app-server=, so running it in the same
  container gives it the same Codex binary, OAuth state under =~/.codex=, and
  mounted =/work= view as terminal Codex.
- Use =/work= as the canonical host and in-container workspace root. These are
  separate filesystems connected only through the explicit bind mount.
- Externally reachable AI services should prefer the manually chosen host port
  prefix defined in [[*Setup constants][Setup constants]]. T3 Web uses the T3
  public port constant; internal-only ports such as MCP =8000= should stay
  unpublished unless deliberately promoted.
- The throwaway/no-auth lane is intentionally skipped for now. One-shot and
  no-auth work should use host-installed tools directly unless that becomes
  too painful or risky.
- A small user =t3-web.service= is the clean background-start option for T3.
  Quadlet is still the right layer for the long-lived container itself, but a
  regular systemd service is a better fit for a foreground process started with
  =podman exec= inside that container.
- The base image is pinned to Fedora 44. Quay's =quay.io/fedora/fedora= image
  is the normal Fedora container base; keep the release pin rather than using
  =latest= so rebuilds are predictable.

aiagent-backup() {
    local include_work=0 dest stamp out dest_display
    dest="$AIAGENT_WORK_ROOT/ai/backups"

    while [[ $# -gt 0 ]]; do
        case "$1" in
            --include-work)
                include_work=1
                shift
                ;;
            -h|--help)
                cat <<'EOF'
Usage:
  aiagent-backup [--include-work] [DEST_DIR]

Archives aiagent persistent state to DEST_DIR. By default this includes the
agent config/state bind mounts and named toolchain/cache volumes, but excludes
<<aiagent-host-work-root()>> because project workspaces can be large.
EOF
                return 0
                ;;
            -*)
                printf 'aiagent-backup: unknown option: %s\n' "$1" >&2
                return 2
                ;;
            *)
                dest="$1"
                shift
                ;;
        esac
    done

    mkdir -p "$dest" || return
    dest="$(cd "$dest" && pwd -P)" || return
    stamp="$(date -u +%Y%m%dT%H%M%SZ)"
    out="aiagent-backup-${stamp}.tar.gz"

    local podman_args=(
        run
        --rm
        --pull=never
        --security-opt label=disable
        -v /home/aiagent/aiagent_container:/backup/aiagent_container:ro
        -v android-sdk.volume:/backup/volumes/android-sdk:ro
        -v gradle-cache.volume:/backup/volumes/gradle-cache:ro
        -v cabal-cache.volume:/backup/volumes/cabal-cache:ro
        -v ghcup-cache.volume:/backup/volumes/ghcup-cache:ro
        -v "$dest:/out:Z"
    )
    local tar_paths=(aiagent_container volumes)

    if [[ "$include_work" -eq 1 ]]; then
        podman_args+=(-v "$AIAGENT_WORK_ROOT:/backup/work:ro")
        tar_paths+=(work)
    fi

    _aiagent "${podman_args[@]}" localhost/aiagent:latest \
        tar -C /backup -czf "/out/$out" "${tar_paths[@]}"

    dest_display="$dest/$out"
    printf 'aiagent backup written: %s\n' "$dest_display"
}

slugify() {

session_suffix() {
    local repo_slug="$1" selected="$2" name="${3:-}"
    local suffix
    if [[ -n "$name" ]]; then
        suffix="$name"
    elif [[ "$selected" == "." ]]; then
        suffix="$repo_slug"
    else
        suffix="$repo_slug-$(basename "$selected")"
    fi
    suffix="$(slugify "$suffix")"
    [[ -n "$suffix" ]] || suffix="session"
    printf '%s\n' "$suffix"
}

abs_path() {

        base="$(basename "$path")"
        (cd "$dir" && printf '%s/%s\n' "$(pwd -P)" "$base")
    fi
}

    case "$abs" in
        "$root") printf '.\n' ;;
        "$root"/*) printf '%s\n' "${abs#"$root"/}" ;;
        ,*) die "path is outside source root: $path" ;;
    esac
}

session_dir() {
    local id="$1"
    printf '%s/sessions/%s\n' "$AI_WORK_ROOT" "$id"
}

session_status() {
    local dir="$1"
    local state="$dir/ai-work.state.json"
    if [[ -f "$state" ]]; then
        jq -r '.status // "pending"' "$state" 2>/dev/null || printf 'pending\n'
    elif [[ -f "$dir/done" ]]; then
        printf 'done\n'
    elif [[ -f "$dir/aborted" ]]; then
        printf 'aborted\n'
    else
        printf 'pending\n'
    fi
}

list_session_dirs() {
    local filter="${1:-pending}" root session status
    for root in "$AI_WORK_ROOT" <<aiagent-container-ai-root()>>; do
        [[ -d "$root/sessions" ]] || continue
        find "$root/sessions" -mindepth 1 -maxdepth 1 -type d 2>/dev/null
    done | sort -u |
        while IFS= read -r session; do
            [[ -f "$session/manifest.json" ]] || continue
            status="$(session_status "$session")"
            [[ "$filter" == "all" || "$status" == "$filter" ]] || continue
            printf '%s\n' "$session"
        done
}

session_line() {
    local dir="$1"
    local manifest="$dir/manifest.json" status agent source
    status="$(session_status "$dir")"
    agent="$(jq -r '.agent // "unknown"' "$manifest" 2>/dev/null)"
    source="$(jq -r '.source_root // "unknown"' "$manifest" 2>/dev/null)"
    printf '%s\t%s\t%s\t%s\n' "$(basename "$dir")" "$status" "$agent" "$source"
}

pick_session() {
    local filter="${1:-pending}" sessions_file choice count line
    mkdir -p "$AI_WORK_ROOT/tmp"
    sessions_file="$(mktemp "$AI_WORK_ROOT/tmp/sessions.XXXXXX")"
    list_session_dirs "$filter" >"$sessions_file"
    count="$(wc -l <"$sessions_file" | tr -d ' ')"
    if [[ "$count" -eq 0 ]]; then
        rm -f "$sessions_file"
        die "no $filter sessions found"
    fi

    if command -v fzf >/dev/null 2>&1 && [[ -r /dev/tty && -w /dev/tty ]]; then
        choice="$(while IFS= read -r line; do session_line "$line"; done <"$sessions_file" |
      fzf --prompt='ai session> ' --with-nth=1,2,3,4 | cut -f1)"
        rm -f "$sessions_file"
        [[ -n "$choice" ]] || die "no session selected"
        printf '%s\n' "$choice"
        return
    fi

    if [[ ! -r /dev/tty || ! -w /dev/tty ]]; then
        rm -f "$sessions_file"
        die "missing session id and no interactive picker is available; run ai-list --$filter"
    fi

    local i=1 ids=()
    while IFS= read -r line; do
        ids+=("$(basename "$line")")
        printf '%3d  ' "$i" >/dev/tty
        session_line "$line" | tr '\t' ' ' >/dev/tty
        i=$((i + 1))
    done <"$sessions_file"
    rm -f "$sessions_file"
    printf 'Select session: ' >/dev/tty
    read -r choice </dev/tty
    [[ "$choice" =~ ^[0-9]+$ ]] || die "invalid selection: $choice"
    [[ "$choice" -ge 1 && "$choice" -le "${#ids[@]}" ]] || die "selection out of range: $choice"
    printf '%s\n' "${ids[$((choice - 1))]}"
}

resolve_session_arg() {
    local id="${1:-}"
    if [[ -z "$id" ]]; then
        pick_session pending
    else
        printf '%s\n' "$id"
    fi
}

find_session() {

            return
        fi

    die "unknown session: $id"
}

normalize_session_permissions() {
    local dir="$1"
    [[ -d "$dir" ]] || return 0

    find "$dir" -type d -exec chmod ug+rwx,o-rwx,g+s {} + 2>/dev/null || true
    find "$dir" -type f -exec chmod ug+rw,o-rwx {} + 2>/dev/null || true

    if getent group "$AI_SHARED_GROUP" >/dev/null 2>&1; then
        chgrp -R "$AI_SHARED_GROUP" "$dir" 2>/dev/null || true
    fi

    if command -v setfacl >/dev/null 2>&1; then
        local acl_entries=("g:${AI_SHARED_GROUP}:rwX" "m::rwX")
        local default_entries=("g:${AI_SHARED_GROUP}:rwx" "m::rwx")
        if [[ -n "$AI_HOST_USER" ]]; then
            acl_entries+=("u:${AI_HOST_USER}:rwX")
            default_entries+=("u:${AI_HOST_USER}:rwx")
        fi
        if [[ -n "$AI_AGENT_USER" ]]; then
            acl_entries+=("u:${AI_AGENT_USER}:rwX")
            default_entries+=("u:${AI_AGENT_USER}:rwx")
        fi
        setfacl -R -m "$(IFS=,; printf '%s' "${acl_entries[*]}")" "$dir" 2>/dev/null || true
        find "$dir" -type d -exec setfacl -d -m "$(IFS=,; printf '%s' "${default_entries[*]}")" {} + 2>/dev/null || true
    fi
}

resolve_under_shared_work() {
    local dest="$1" root="$2" parent resolved
    root="$(realpath -m "$root")"
    if [[ "$dest" = /* ]]; then
        if [[ -e "$dest" ]]; then
            resolved="$(realpath -m "$dest")"
        else
            parent="$(dirname "$dest")"
            [[ -d "$parent" ]] || die "destination parent does not exist: $parent"
            resolved="$(realpath -m "$parent")/$(basename "$dest")"
        fi
    else
        [[ "$dest" != *..* ]] || die "relative destination must not contain '..': $dest"
        resolved="$(realpath -m "$root/$dest")"
    fi

    case "$resolved" in
        "$root"|"$root"/*) printf '%s\n' "$resolved" ;;
        ,*) die "destination must resolve under $root: $dest" ;;
    esac
}

default_source() {
    local source_mode="$1"
    if [[ "$source_mode" == "dot" || "$source_mode" == "bare" ]]; then
        local dot_git_dir
        dot_git_dir="$(load_dot_git_dir)"
        [[ -d "$dot_git_dir" ]] || die "dotfiles git dir not found: $dot_git_dir"
        printf 'bare-git\n%s\n%s\n%s\n' "$AI_DOT_WORK_TREE" "$dot_git_dir" dotfiles
        return
    fi

    if git_root="$(git rev-parse --show-toplevel 2>/dev/null)"; then
        printf 'git\n%s\n%s\n%s\n' "$git_root" "$(git -C "$git_root" rev-parse --git-dir)" "$(basename "$git_root")"
    else
        printf 'plain\n%s\n\n%s\n' "$(pwd -P)" "$(basename "$(pwd -P)")"
    fi
}

select_git_paths() {
    local source_kind="$1" source_root="$2" git_dir="$3" selector="$4"
    shift 4
    local scopes=("$@")
    local git_cmd=(git)
    [[ ${#scopes[@]} -gt 0 ]] || scopes=(.)
    if [[ "$source_kind" == "bare-git" ]]; then
        git_cmd=(git --git-dir="$git_dir" --work-tree="$source_root")
    else
        git_cmd=(git -C "$source_root")
    fi

    local scope
    for scope in "${scopes[@]}"; do
        case "$selector" in
            tracked)
                "${git_cmd[@]}" ls-files -- "$scope"
                ;;
            staged)
                "${git_cmd[@]}" diff --cached --name-only -- "$scope"
                ;;
            dirty)
                {
                    "${git_cmd[@]}" diff --name-only -- "$scope"
                    "${git_cmd[@]}" diff --cached --name-only -- "$scope"
                }
                ;;
            ,*)
                die "unknown selector: $selector"
                ;;
        esac
    done | sort -u
}

collect_paths() {
    local source_kind="$1" source_root="$2" git_dir="$3" selector="$4"
    shift 4
    local paths=("$@")

    if [[ -n "$selector" ]]; then
        select_git_paths "$source_kind" "$source_root" "$git_dir" "$selector" "${paths[@]}"
        return
    fi

    if [[ ${#paths[@]} -eq 0 ]]; then
        rel_path "$source_root" "$(pwd -P)"
        return
    fi

    local p
    for p in "${paths[@]}"; do
        rel_path "$source_root" "$p"
    done
}

copy_rel_path() {
    local source_root="$1" rel="$2" dest_root="$3"
    local src="$source_root/$rel"

    if [[ "$rel" == "." ]]; then
        (cd "$source_root" && tar --exclude .git -cf - .) | (mkdir -p "$dest_root" && cd "$dest_root" && tar -xf -)
        return
    fi

    [[ -e "$src" ]] || die "selected path does not exist: $src"
    mkdir -p "$dest_root/$(dirname "$rel")"
    cp -a "$src" "$dest_root/$rel"
}

copy_selected_paths() {

    while IFS= read -r rel; do
        [[ -n "$rel" ]] || continue

is_same_path() {
    local a="$1" b="$2"
    [[ "$(abs_path "$a")" == "$(abs_path "$b")" ]]
}

validate_selected_paths() {
    local source_root="$1" paths_file="$2" force_top="$3"
    local home_abs rel src
    home_abs="$(abs_path "$HOME")"

    if is_same_path "$source_root" "$home_abs"; then
        while IFS= read -r rel; do
            [[ -n "$rel" ]] || continue
            src="$source_root/$rel"
            if [[ -d "$src" && ( "$rel" == "." || "$rel" != */* ) && "$force_top" != "1" ]]; then
                die "refusing to copy top-level home directory '$rel'; pass --force-copy-top-level-dir to allow it"
            fi
        done <"$paths_file"
    fi
}

estimate_selected_paths() {
    local source_root="$1" paths_file="$2" output="$3"
    local files_tmp rel src file_count total_bytes
    files_tmp="$(mktemp "$AI_WORK_ROOT/tmp/files.XXXXXX")"

    while IFS= read -r rel; do
        [[ -n "$rel" ]] || continue
        src="$source_root/$rel"
        [[ -e "$src" ]] || die "selected path does not exist: $src"
        if [[ -d "$src" ]]; then
            (cd "$source_root" && find "$rel" -path '*/.git' -prune -o -type f -print)
        elif [[ -f "$src" ]]; then
            printf '%s\n' "$rel"
        fi
    done <"$paths_file" | sort -u >"$files_tmp"

    file_count="$(wc -l <"$files_tmp" | tr -d ' ')"
    total_bytes="$(while IFS= read -r rel; do [[ -f "$source_root/$rel" ]] && stat -c '%s' "$source_root/$rel"; done <"$files_tmp" | awk '{s+=$1} END {print s+0}')"
    printf '%s\t%s\n' "$file_count" "$total_bytes" >"$output"
    rm -f "$files_tmp"
}

enforce_copy_limits() {
    local estimate_file="$1" force_large="$2" max_files="$3" max_bytes="$4"
    local file_count total_bytes
    IFS=$'\t' read -r file_count total_bytes <"$estimate_file"

    if [[ "$force_large" != "1" && ( "$file_count" -gt "$max_files" || "$total_bytes" -gt "$max_bytes" ) ]]; then
        die "refusing large copy (${file_count} files, ${total_bytes} bytes); pass --force-large-copy to allow it"
    fi
}

write_source_hashes() {
    local source_root="$1" worktree="$2" output="$3"
    : >"$output"
    (cd "$worktree" && find . -path ./.git -prune -o -type f -print | sort) |
        while IFS= read -r rel; do
            rel="${rel#./}"
            if [[ -f "$source_root/$rel" ]]; then
                printf '%s\t%s\n' "$(sha256sum "$source_root/$rel" | awk '{print $1}')" "$rel" >>"$output"
            else
                printf 'MISSING\t%s\n' "$rel" >>"$output"
            fi
        done
}

check_source_hashes() {
    local source_root="$1" hashes="$2"
    local expected rel actual failed=0
    while IFS=$'\t' read -r expected rel; do
        [[ -n "${rel:-}" ]] || continue
        if [[ -f "$source_root/$rel" ]]; then
            actual="$(sha256sum "$source_root/$rel" | awk '{print $1}')"
        else
            actual="MISSING"
        fi
        if [[ "$actual" != "$expected" ]]; then
            printf 'source changed since session creation: %s\n' "$rel" >&2
            failed=1
        fi
    done <"$hashes"
    [[ "$failed" == "0" ]]
}

write_copyback_manifest() {
    local session_dir="$1" output="$2"
    local manifest="$session_dir/manifest.json" worktree source_root tmp
    mkdir -p "$AI_WORK_ROOT/tmp"
    worktree="$(load_manifest_value "$manifest" '.session_worktree')"
    source_root="$(load_manifest_value "$manifest" '.source_root')"
    tmp="$(mktemp "$AI_WORK_ROOT/tmp/changed.XXXXXX")"
    git -C "$worktree" diff --name-status -- . ':(exclude).ai-work/context/**' >"$tmp"
    jq -R -s --arg source_root "$source_root" --arg worktree "$worktree" '
    split("\n")
    | map(select(length > 0) | split("\t") as $p | {
        status: $p[0],
        path: (if ($p[0] | startswith("R")) then $p[2] else $p[1] end),
        old_path: (if ($p[0] | startswith("R")) then $p[1] else null end)
      })
    | {
        source_root: $source_root,
        worktree: $worktree,
        generated_at: now | strftime("%Y-%m-%dT%H:%M:%SZ"),
        changes: map(. + {
          source_path: ($source_root + "/" + .path),
          worktree_path: ($worktree + "/" + .path)
        })
      }' "$tmp" >"$output"
    rm -f "$tmp"
}

copy_back_changes() {
    local copyback="$1" delete_allowed="$2"
    local source_root worktree status rel src dst
    source_root="$(jq -r '.source_root' "$copyback")"
    worktree="$(jq -r '.worktree' "$copyback")"

    jq -r '.changes[] | [.status, .path] | @tsv' "$copyback" |
        while IFS=$'\t' read -r status rel; do
            [[ -n "$rel" ]] || continue
            case "$status" in
                D)
                    if [[ "$delete_allowed" == "1" ]]; then
                        rm -f "$source_root/$rel"
                        printf 'Deleted: %s\n' "$source_root/$rel"
                    else
                        printf 'Skipped delete: %s (pass --delete to allow)\n' "$source_root/$rel" >&2
                    fi
                    ;;
                ,*)
                    src="$worktree/$rel"
                    dst="$source_root/$rel"
                    [[ -e "$src" ]] || die "changed worktree path is missing: $src"
                    mkdir -p "$(dirname "$dst")"
                    cp -a "$src" "$dst"
                    printf 'Copied: %s\n' "$dst"
                    ;;
            esac
        done
}

    local worktree="$1" id="$2" source_root="$3" paths_file="$4" prompt="$5" mode="${6:-snapshot}"
    {
        printf '# AI Work Session\n\n'
        printf '%s\n' "- Session: \`$id\`"
        printf '%s\n' "- Source: \`$source_root\`"
        printf '%s\n' "- Return path: tell the user to run host command \`ai-done $id\`; do not run \`ai-done\` from inside the container and do not write to the source tree directly."
        printf '%s\n\n' "- Container path: use \`<<aiagent-container-work-root()>>\`."
        if [[ "$mode" == "history" || "$mode" == "clone" ]]; then
            printf '%s\n\n' "- History: this workspace is a Git clone; inspect the visible commit log/history and follow existing project patterns before editing."
        fi
        printf '## Selected Paths\n\n'
        sed 's/^/- `/' "$paths_file" | sed 's/$/`/'
        if [[ -n "$prompt" ]]; then
            printf '\n## Prompt\n\n%s\n' "$prompt"
        fi
    } >"$worktree/AGENTS.md"
}

history_clone() {
    local mode="$1" source_kind="$2" source_root="$3" git_dir="$4" paths_file="$5" worktree="$6"
    need git
    if [[ "$mode" == "history" ]]; then
        need git-filter-repo
    fi

    mkdir -p "$(dirname "$worktree")"
    if [[ "$source_kind" == "bare-git" ]]; then
        git clone --no-local "$git_dir" "$worktree" >/dev/null || die "git clone failed: $git_dir"
    else
        git clone --no-local "$source_root" "$worktree" >/dev/null || die "git clone failed: $source_root"
    fi

    if [[ "$mode" == "history" ]] && ! grep -qxF . "$paths_file"; then
        local args=()
        while IFS= read -r rel; do
            [[ -n "$rel" ]] || continue
            args+=(--path "$rel")
        done <"$paths_file"
        (cd "$worktree" && git filter-repo "${args[@]}" >/dev/null) || die "git filter-repo failed"
    fi
    if [[ "$mode" == "history" ]]; then
        copy_selected_paths "$source_root" "$worktree" "$paths_file"
    fi
}

prepare_clone_paths() {
    local source_root="$1"
    shift
    local paths=("$@")

    if [[ ${#paths[@]} -eq 0 ]]; then
        printf '.\n'
        return
    fi

    if [[ ${#paths[@]} -ne 1 ]]; then
        die "--clone accepts only the whole repo; omit paths or pass '.'"
    fi

    if [[ "$(rel_path "$source_root" "${paths[0]}")" != "." ]]; then
        die "--clone accepts only the whole repo; omit paths or pass '.'"
    fi

    printf '.\n'
}

copy_history_or_clone_to_shared_work() {
    local mode="$1" source_kind="$2" source_root="$3" git_dir="$4" repo_slug="$5" paths_file="$6" copy_to="$7" name="$8"
    local root dest tmp first_path out_name worktree final_path container_path

    [[ "$mode" == "history" || "$mode" == "clone" ]] || die "--copy-to requires --history or --clone"
    if [[ "$mode" == "history" ]]; then
        need git-filter-repo
    fi

    root="$(shared_work_root)"
    dest="$(resolve_under_shared_work "$copy_to" "$root")"
    mkdir -p "$dest"
    [[ -d "$dest" ]] || die "copy destination is not a directory: $dest"

    first_path="$(head -n1 "$paths_file")"
    out_name="$(session_suffix "$repo_slug" "$first_path" "$name")"
    [[ -n "$out_name" ]] || out_name="clone"
    final_path="$dest/$out_name"
    [[ ! -e "$final_path" ]] || die "destination already exists: $final_path"

    tmp="$(mktemp -d "$AI_WORK_ROOT/tmp/copy-to.XXXXXX")"
    worktree="$tmp/$out_name"
    if ! history_clone "$mode" "$source_kind" "$source_root" "$git_dir" "$paths_file" "$worktree"; then
        rm -rf "$tmp"
        exit 1
    fi

    cp -a "$worktree" "$dest/"
    rm -rf "$tmp"
    normalize_session_permissions "$final_path"

    container_path="$final_path"
    case "$container_path" in
        <<aiagent-host-work-root()>>|<<aiagent-host-work-root()>>/*) container_path="<<aiagent-container-work-root()>>${container_path#<<aiagent-host-work-root()>>}" ;;
    esac

    printf 'Copied to: %s\n' "$final_path"
    printf 'Container path: %s\n' "$container_path"
}

make_session() {
    local agent="t3" mode="snapshot" source_mode="normal" name="" selector="" read_only=0 prompt="" no_launch=0 copy_to="" force_top=0 force_large=0 max_files="$AI_WORK_MAX_COPY_FILES" max_bytes="$AI_WORK_MAX_COPY_BYTES"
    local paths=()

    while [[ $# -gt 0 ]]; do
        case "$1" in
            --agent) agent="${2:?missing --agent value}"; shift 2 ;;
            --history) mode="history"; shift ;;
            --clone) mode="clone"; shift ;;
            --source-mode-dot) source_mode="dot"; mode="history"; shift ;;
            --source-mode-bare) source_mode="bare"; mode="clone"; shift ;;
            --name) name="${2:?missing --name value}"; shift 2 ;;
            --copy-to) copy_to="${2:?missing --copy-to value}"; no_launch=1; shift 2 ;;
            --tracked|--staged|--dirty) selector="${1#--}"; shift ;;
            --readonly) read_only=1; shift ;;
            --no-launch) no_launch=1; shift ;;
            --force-copy-top-level-dir) force_top=1; shift ;;
            --force-large-copy) force_large=1; shift ;;
            --max-copy-files) max_files="${2:?missing --max-copy-files value}"; shift 2 ;;
            --max-copy-bytes) max_bytes="${2:?missing --max-copy-bytes value}"; shift 2 ;;
            --prompt) prompt="${2:?missing --prompt value}"; shift 2 ;;
            --) shift; prompt="${*:-}"; break ;;
            -h|--help) usage; exit 0 ;;
            ,*) paths+=("$1"); shift ;;
        esac
    done

    [[ "$agent" =~ ^(t3|codex|opencode)$ ]] || die "unknown agent: $agent"
    if [[ -n "$copy_to" && "$mode" == "snapshot" ]]; then
        die "--copy-to requires --history or --clone"
    fi
    if [[ "$agent" == "t3" && "$no_launch" != "1" ]]; then
        ensure_t3_ready
    fi

    need jq
    need sha256sum
    mkdir -p "$AI_WORK_ROOT/sessions" "$AI_WORK_ROOT/outbox" "$AI_WORK_ROOT/tmp"

    mapfile -t source_info < <(default_source "$source_mode")
    local source_kind="${source_info[0]}" source_root="${source_info[1]}" git_dir="${source_info[2]}" repo_slug
    repo_slug="$(slugify "${source_info[3]}")"
    [[ -n "$repo_slug" ]] || repo_slug="plain"

    if [[ "$mode" == "clone" ]]; then
        [[ -n "$git_dir" ]] || die "--clone requires a git or bare-git source"
        [[ -z "$selector" ]] || die "--clone cannot be combined with --tracked, --staged, or --dirty"
    fi
    if [[ -n "$copy_to" && -n "$selector" ]]; then
        die "--copy-to cannot be combined with --tracked, --staged, or --dirty"
    fi
    if [[ "$mode" == "history" ]]; then
        need git-filter-repo
    fi

    local paths_file
    paths_file="$(mktemp "$AI_WORK_ROOT/tmp/paths.XXXXXX")"
    if [[ "$mode" == "clone" ]]; then
        prepare_clone_paths "$source_root" "${paths[@]}" >"$paths_file"
    else
        collect_paths "$source_kind" "$source_root" "$git_dir" "$selector" "${paths[@]}" | sed '/^$/d' | sort -u >"$paths_file"
    fi
    [[ -s "$paths_file" ]] || die "no paths selected"

    local estimate_file selected_files=0 selected_bytes=0
    if [[ "$mode" != "clone" ]]; then
        validate_selected_paths "$source_root" "$paths_file" "$force_top"
        estimate_file="$(mktemp "$AI_WORK_ROOT/tmp/estimate.XXXXXX")"
        estimate_selected_paths "$source_root" "$paths_file" "$estimate_file"
        enforce_copy_limits "$estimate_file" "$force_large" "$max_files" "$max_bytes"
        IFS=$'\t' read -r selected_files selected_bytes <"$estimate_file"
        rm -f "$estimate_file"
    fi

    if [[ -n "$copy_to" ]]; then
        copy_history_or_clone_to_shared_work "$mode" "$source_kind" "$source_root" "$git_dir" "$repo_slug" "$paths_file" "$copy_to" "$name"
        rm -f "$paths_file"
        return 0
    fi

    local stamp id dir worktree baseline container_worktree suffix first_path
    stamp="$(date -u +%Y%m%d-%H%M%S)"
    first_path="$(head -n1 "$paths_file")"
    suffix="$(session_suffix "$repo_slug" "$first_path" "$name")"
    id="$stamp-$suffix"
    dir="$(session_dir "$id")"
    worktree="$dir/worktree"
    baseline="$dir/baseline"
    container_worktree="$AI_CONTAINER_WORK_ROOT/sessions/$id/worktree"
    mkdir -p "$dir"

    if [[ "$mode" == "history" || "$mode" == "clone" ]]; then
        if ! history_clone "$mode" "$source_kind" "$source_root" "$git_dir" "$paths_file" "$worktree"; then
            rm -rf "$dir"
            exit 1
        fi
        ensure_session_local_excludes "$worktree"
        write_agents_md "$worktree" "$id" "$source_root" "$paths_file" "$prompt" "$mode"
        [[ -n "$prompt" ]] && printf '%s\n' "$prompt" >"$worktree/PROMPT.md"
        commit_session_baseline "$worktree" 'ai-work current source baseline'
    else
        mkdir -p "$worktree"
        copy_selected_paths "$source_root" "$worktree" "$paths_file"
        git -C "$worktree" init -q
        ensure_session_local_excludes "$worktree"
        write_agents_md "$worktree" "$id" "$source_root" "$paths_file" "$prompt" "$mode"
        [[ -n "$prompt" ]] && printf '%s\n' "$prompt" >"$worktree/PROMPT.md"
        commit_session_baseline "$worktree" 'ai-work baseline'
    fi

    cp -a "$worktree" "$baseline"
    write_source_hashes "$source_root" "$worktree" "$dir/source.sha256"
    cp "$paths_file" "$dir/paths.txt"
    write_manifest "$dir/manifest.json" "$id" "$mode" "$agent" "$source_kind" "$source_root" "$git_dir" "$repo_slug" "$worktree" "$container_worktree" "$paths_file" "$prompt" "$read_only" "$force_top" "$force_large" "$max_files" "$max_bytes" "$selected_files" "$selected_bytes"
    jq -n --arg id "$id" --arg created_at "$(date -u +%Y-%m-%dT%H:%M:%SZ)" \
       '{id: $id, status: "pending", created_at: $created_at, updated_at: $created_at}' >"$dir/ai-work.state.json"
    [[ "$no_launch" == "1" ]] && touch "$dir/no-launch"
    rm -f "$paths_file"
    normalize_session_permissions "$dir"

    printf '%s\n' "$id"
}

cmd_edit_dot() {
    local original=("$@") has_path=0
    while [[ $# -gt 0 ]]; do
        case "$1" in
            --clone|--dot) die "ai-edit-dot always uses filtered history for explicit paths" ;;
            --agent|--name|--copy-to|--max-copy-files|--max-copy-bytes|--prompt)
                [[ $# -ge 2 ]] || die "missing $1 value"
                shift 2
                ;;
            --history|--tracked|--staged|--dirty|--readonly|--no-launch|--force-copy-top-level-dir|--force-large-copy)
                shift
                ;;
            --)
                shift
                [[ $# -gt 0 ]] && has_path=1
                break
                ;;
            -*)
                die "unknown ai-edit-dot option: $1"
                ;;
            ,*)
                has_path=1
                shift
                ;;
        esac
    done
    [[ "$has_path" == "1" ]] || die "ai-edit-dot requires at least one path"
    cmd_edit --history --source-mode-dot "${original[@]}"
}

cmd_copy() {
    [[ $# -ge 2 ]] || die "Usage: ai-copy SOURCE... WORK-DIR"
    local dest_arg="${!#}"
    local sources=("${@:1:$(($# - 1))}")

    local root dest source dest_dir
    root="$(shared_work_root)"
    dest="$(resolve_under_shared_work "$dest_arg" "$root")"
    mkdir -p "$dest"
    [[ -d "$dest" ]] || die "destination is not a directory: $dest"

    for source in "${sources[@]}"; do
        [[ -e "$source" ]] || die "source does not exist: $source"
        cp -a "$source" "$dest/"
    done
    dest_dir="$dest"
    normalize_session_permissions "$dest_dir"
    printf 'Copied to: %s\n' "$dest_dir"
}

launch_agent() {
    local id="$1"
    local dir manifest agent container_worktree read_only prompt project_id thread_id browser_url
    dir="$(find_session "$id")"
    manifest="$dir/manifest.json"
    agent="$(load_manifest_value "$manifest" '.agent')"
    container_worktree="$(load_manifest_value "$manifest" '.container_worktree')"
    read_only="$(load_manifest_value "$manifest" '.readonly')"
    prompt="$(load_manifest_value "$manifest" '.prompt')"

    case "$agent" in
        t3)
            ensure_t3_ready
            t3_project_add "$id" "$container_worktree"
            project_id="$(t3_project_id_for_workspace "$container_worktree")"
            thread_id="$(t3_latest_thread_id_for_project "$project_id")"
            browser_url="$(t3_browser_url "$project_id" "$thread_id")"
            write_session_state "$dir" t3_project_workspace "$container_worktree"
            write_session_state "$dir" t3_project_id "$project_id"
            write_session_state "$dir" t3_thread_id "$thread_id"
            write_session_state "$dir" t3_browser_url "$browser_url"
            if [[ -n "$thread_id" ]]; then
                command -v xdg-open >/dev/null 2>&1 && xdg-open "$browser_url" >/dev/null 2>&1 || true
            fi
            printf 'T3 project registered: %s\n' "$container_worktree"
            printf 'T3 project: %s\n' "$project_id"
            if [[ -n "$thread_id" ]]; then
                printf 'T3 thread: %s\n' "$thread_id"
                printf 'T3 URL: %s\n' "$browser_url"
            else
                printf 'T3 project URL: %s\n' "$browser_url"
            fi
            printf 'When done: ai-done %s\n' "$id"
            ;;
        codex)
            if [[ "$read_only" == "true" ]]; then
                if [[ -n "$prompt" && "$prompt" != "null" ]]; then
                    run_in_harness_at "$container_worktree" codex exec --sandbox read-only --ask-for-approval never --cd "$container_worktree" "$prompt"
                else
                    run_in_harness_interactive_at "$container_worktree" codex --sandbox read-only --ask-for-approval never --cd "$container_worktree"
                fi
            else
                run_in_harness_interactive_at "$container_worktree" codex-auto
            fi
            ;;
        opencode)
            run_in_harness_interactive_at "$container_worktree" opencode "$container_worktree"
            ;;
    esac
}

cmd_edit() {
    local id is_copy_to=0 arg
    for arg in "$@"; do
        if [[ "$arg" == "--copy-to" ]]; then
            is_copy_to=1
            break
        fi
    done
    if [[ "$is_copy_to" == "1" ]]; then
        make_session "$@"
        return
    fi

    if ! id="$(make_session "$@")"; then
        exit 1
    fi
    printf 'Session: %s\n' "$id"
    printf 'Workspace: %s\n' "$(session_dir "$id")/worktree"
    [[ -f "$(session_dir "$id")/no-launch" ]] && return 0
    launch_agent "$id"
}

cmd_add() {
    local id="" context=0 paths=()
    mkdir -p "$AI_WORK_ROOT/tmp"
    while [[ $# -gt 0 ]]; do
        case "$1" in
            --context) context=1; shift ;;
            -h|--help)
                printf 'Usage: ai-add [SESSION] [--context] PATH...\n'
                return 0
                ;;
            ,*)
                if [[ -z "$id" && -n "${1:-}" && ! -e "$1" ]]; then
                    id="$1"
                else
                    paths+=("$1")
                fi
                shift
                ;;
        esac
    done
    id="$(resolve_session_arg "$id")"
    [[ ${#paths[@]} -gt 0 ]] || die "missing paths to add"

    local dir manifest worktree source_root rel p
    dir="$(find_session "$id")"
    manifest="$dir/manifest.json"
    worktree="$(load_manifest_value "$manifest" '.session_worktree')"
    source_root="$(load_manifest_value "$manifest" '.source_root')"

    if [[ "$context" == "1" ]]; then
        mkdir -p "$worktree/.ai-work/context"
        printf '.ai-work/context/\n' >>"$worktree/.git/info/exclude"
        sort -u "$worktree/.git/info/exclude" -o "$worktree/.git/info/exclude"
        for p in "${paths[@]}"; do
            [[ -e "$p" ]] || die "context path does not exist: $p"
            copy_context_path "$p" "$worktree"
        done
        normalize_session_permissions "$dir"
        write_session_state "$dir" context_updated "true"
        printf 'Added context to session: %s\n' "$id"
        return
    fi

    local paths_tmp
    paths_tmp="$(mktemp "$AI_WORK_ROOT/tmp/add-paths.XXXXXX")"
    for p in "${paths[@]}"; do
        rel="$(rel_path "$source_root" "$p")"
        printf '%s\n' "$rel" >>"$paths_tmp"
    done
    sort -u "$paths_tmp" -o "$paths_tmp"
    copy_selected_paths "$source_root" "$worktree" "$paths_tmp"
    while IFS= read -r rel; do
        append_unique_path "$dir/paths.txt" "$rel"
    done <"$paths_tmp"
    write_source_hashes "$source_root" "$worktree" "$dir/source.sha256"
    commit_paths_baseline "$worktree" "ai-work add baseline" "$paths_tmp"
    normalize_session_permissions "$dir"
    write_session_state "$dir" paths_updated "true"
    rm -f "$paths_tmp"
    printf 'Added baseline paths to session: %s\n' "$id"
}

cmd_done() {
    local id
    id="$(resolve_session_arg "${1:-}")"
    local dir manifest worktree repo_slug outdir patch copyback
    dir="$(find_session "$id")"
    manifest="$dir/manifest.json"
    worktree="$(load_manifest_value "$manifest" '.session_worktree')"
    repo_slug="$(load_manifest_value "$manifest" '.repo_slug')"
    outdir="$AI_WORK_ROOT/outbox/$repo_slug"
    patch="$outdir/$id.patch"
    copyback="$outdir/$id.copyback.json"
    mkdir -p "$outdir"
    normalize_session_permissions "$dir"
    git -C "$worktree" add -N . >/dev/null 2>&1 || true
    if git -C "$worktree" diff --quiet --exit-code; then
        die "no changes in session: $id"
    fi
    git -C "$worktree" diff --binary -- . ':(exclude).ai-work/context/**' >"$patch"
    write_copyback_manifest "$dir" "$copyback"
    cp "$manifest" "$outdir/$id.manifest.json"
    cp "$dir/source.sha256" "$outdir/$id.source.sha256"
    touch "$dir/done"
    write_session_state "$dir" status "done"
    write_session_state "$dir" patch "$patch"
    write_session_state "$dir" copyback_manifest "$copyback"
    printf 'Patch: %s\n' "$patch"
    printf 'Manifest: %s\n' "$outdir/$id.manifest.json"
    printf 'Copyback: %s\n' "$copyback"
}

cmd_apply() {
    local target="${1:?missing session id or patch}"
    shift || true
    local force=0
    while [[ $# -gt 0 ]]; do
        case "$1" in
            --force) force=1; shift ;;
            ,*) die "unknown ai-apply option: $1" ;;
        esac
    done

    local manifest patch id dir
    if [[ -f "$target" ]]; then
        patch="$(abs_path "$target")"
        manifest="${patch%.patch}.manifest.json"
        [[ -f "$manifest" ]] || die "manifest not found beside patch: $manifest"
    else
        id="$target"
        dir="$(find_session "$id")"
        manifest="$AI_WORK_ROOT/outbox/$(load_manifest_value "$dir/manifest.json" '.repo_slug')/$id.manifest.json"
        patch="$AI_WORK_ROOT/outbox/$(load_manifest_value "$dir/manifest.json" '.repo_slug')/$id.patch"
        [[ -f "$patch" ]] || die "patch not found; run ai-done first: $id"
    fi

    local source_kind source_root git_dir
    source_kind="$(load_manifest_value "$manifest" '.source_kind')"
    source_root="$(load_manifest_value "$manifest" '.source_root')"
    git_dir="$(load_manifest_value "$manifest" '.git_dir')"

    if [[ "$force" == "0" ]]; then
        local hash_file
        if [[ -n "${dir:-}" && -f "$dir/source.sha256" ]]; then
            hash_file="$dir/source.sha256"
        else
            hash_file="$(dirname "$patch")/$(basename "${patch%.patch}").source.sha256"
        fi
        if [[ -f "$hash_file" ]]; then
            check_source_hashes "$source_root" "$hash_file" || die "source drift detected; use --force to apply anyway"
        fi
    fi

    if [[ "$source_kind" == "bare-git" ]]; then
        printf 'Applying with dotfiles bare repo: %s\n' "$patch"
        git --git-dir="$git_dir" --work-tree="$source_root" apply "$patch"
    elif [[ "$source_kind" == "git" ]]; then
        printf 'Applying in repo: %s\n' "$source_root"
        git -C "$source_root" apply "$patch"
    else
        printf 'Applying in plain tree: %s\n' "$source_root"
        (cd "$source_root" && git apply "$patch")
    fi
}

cmd_copy_back() {
    local id="" force=0 delete_allowed=0
    while [[ $# -gt 0 ]]; do
        case "$1" in
            --force) force=1; shift ;;
            --delete) delete_allowed=1; shift ;;
            ,*) id="$1"; shift ;;
        esac
    done
    id="$(resolve_session_arg "$id")"

    local dir manifest source_kind source_root hash_file copyback
    dir="$(find_session "$id")"
    manifest="$dir/manifest.json"
    source_kind="$(load_manifest_value "$manifest" '.source_kind')"
    source_root="$(load_manifest_value "$manifest" '.source_root')"
    [[ "$source_kind" == "plain" ]] || die "ai-copy-back is only for plain sessions; use ai-apply for $source_kind"

    copyback="$(jq -r '.copyback_manifest // empty' "$dir/ai-work.state.json" 2>/dev/null || true)"
    if [[ -z "$copyback" || ! -f "$copyback" ]]; then
        copyback="$AI_WORK_ROOT/outbox/$(load_manifest_value "$manifest" '.repo_slug')/$id.copyback.json"
    fi
    [[ -f "$copyback" ]] || die "copyback manifest not found; run ai-done first: $id"

    if [[ "$force" == "0" ]]; then
        hash_file="$dir/source.sha256"
        if [[ -f "$hash_file" ]]; then
            check_source_hashes "$source_root" "$hash_file" || die "source drift detected; use --force to copy back anyway"
        fi
    fi

    copy_back_changes "$copyback" "$delete_allowed"
}

    dir="$(find_session "$id")"
    container_worktree="$(load_manifest_value "$dir/manifest.json" '.container_worktree')"
    run_in_harness_interactive_at "$container_worktree" /bin/bash
}

cmd_list() {
    local filter="all" session
    while [[ $# -gt 0 ]]; do
        case "$1" in
            --pending) filter="pending"; shift ;;
            --done) filter="done"; shift ;;
            --aborted) filter="aborted"; shift ;;
            --all) filter="all"; shift ;;
            ,*) die "unknown ai-list option: $1" ;;
        esac
    done
    printf 'Sessions:\n'
    list_session_dirs "$filter" |
        while IFS= read -r session; do
            [[ -f "$session/manifest.json" ]] || continue
            session_line "$session" | sed 's/^/  /; s/\t/  /g'
        done
    printf '\nOutbox:\n'
    find "$AI_WORK_ROOT/outbox" -type f -name '*.patch' 2>/dev/null | sort | sed 's/^/  /'
}

cmd_pick() {
    local filter="pending"
    while [[ $# -gt 0 ]]; do
        case "$1" in
            --pending) filter="pending"; shift ;;
            --done) filter="done"; shift ;;
            --aborted) filter="aborted"; shift ;;
            --all) filter="all"; shift ;;
            ,*) die "unknown ai-pick option: $1" ;;
        esac
    done
    pick_session "$filter"
}

cmd_clean() {
    local days=14 status_filter="done|aborted" remove_t3=0
    while [[ $# -gt 0 ]]; do
        case "$1" in
            --older-than) days="${2:?missing day count}"; shift 2 ;;
            --status)
                case "${2:?missing status}" in
                done) status_filter="done" ;;
                aborted) status_filter="aborted" ;;
                all) status_filter="pending|done|aborted" ;;
                ,*) die "unknown status: $2" ;;
                esac
                shift 2
                ;;
            --remove-t3-projects) remove_t3=1; shift ;;
            ,*) die "unknown ai-clean option: $1" ;;
        esac
    done
    find "$AI_WORK_ROOT/sessions" -mindepth 1 -maxdepth 1 -type d -mtime "+$days" -print 2>/dev/null |
        while IFS= read -r dir; do
            local status workspace
            status="$(session_status "$dir")"
            if [[ "$status" =~ ^($status_filter)$ ]]; then
                if [[ "$remove_t3" == "1" && -f "$dir/ai-work.state.json" ]]; then
                    workspace="$(jq -r '.t3_project_workspace // empty' "$dir/ai-work.state.json")"
                    [[ -n "$workspace" ]] && run_in_harness t3 project remove --base-dir "$AI_T3_BASE_DIR" "$workspace" >/dev/null 2>&1 || true
                fi
                printf 'Removing session: %s\n' "$(basename "$dir")"
                rm -rf "$dir"
            fi
        done
}

cmd_status() {
    printf 'AI work root: %s\n' "$AI_WORK_ROOT"
    if command -v sudo >/dev/null 2>&1; then
        printf 'Container: '
        sudo machinectl shell --uid=aiagent .host /usr/bin/podman ps --format '{{.Names}}' 2>/dev/null | grep -qx "$AI_CONTAINER" && printf 'running\n' || printf 'stopped/unknown\n'
    fi
    printf 'T3 URL: %s\n' "$AI_T3_URL"
    printf 'Sessions: %s\n' "$(find "$AI_WORK_ROOT/sessions" -mindepth 1 -maxdepth 1 -type d 2>/dev/null | wc -l)"
    printf 'Outbox patches: %s\n' "$(find "$AI_WORK_ROOT/outbox" -type f -name '*.patch' 2>/dev/null | wc -l)"
}

main() {
    local cmd
    cmd="$(basename "$0")"
    case "$cmd" in
        ai-work) cmd="${1:-}"; [[ $# -gt 0 ]] && shift || true ;;
        ai-edit|ai-edit-dot|ai-edit-bare|aiq|ai-ask|ai-copy|ai-add|ai-done|ai-diff|ai-apply|ai-copy-back|ai-abort|ai-open|ai-shell|ai-list|ai-pick|ai-clean|ai-status) ;;
        ,*) cmd="${1:-}"; [[ $# -gt 0 ]] && shift || true ;;
    esac

    case "$cmd" in
        ai-edit|edit) cmd_edit "$@" ;;
        ai-edit-dot|edit-dot) cmd_edit_dot "$@" ;;
        ai-edit-bare|edit-bare) cmd_edit_bare "$@" ;;
        aiq|q) cmd_edit "$@" ;;
        ai-ask|ask) cmd_edit --readonly --agent codex "$@" ;;
        ai-copy|copy) cmd_copy "$@" ;;
        ai-add|add) cmd_add "$@" ;;
        ai-done|done) cmd_done "$@" ;;
        ai-diff|diff) cmd_diff "$@" ;;
        ai-apply|apply) cmd_apply "$@" ;;
        ai-copy-back|copy-back) cmd_copy_back "$@" ;;
        ai-abort|abort) cmd_abort "$@" ;;
        ai-open|open) cmd_open "$@" ;;
        ai-shell|shell) cmd_shell "$@" ;;
        ai-list|list) cmd_list "$@" ;;
        ai-pick|pick) cmd_pick "$@" ;;
        ai-clean|clean) cmd_clean "$@" ;;
        ai-status|status) cmd_status "$@" ;;
        -h|--help|help|"") usage ;;
        ,*) die "unknown command: $cmd" ;;
    esac
}

main "$@"
